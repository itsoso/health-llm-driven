# 运动教练技术参考手册

## 1. 训练负荷量化

### TRIMP (训练冲量) 公式

TRIMP 是量化单次训练负荷的核心指标：

```
TRIMP = 训练时长(分钟) × 心率强度系数(HRI)
```

心率强度系数计算：

```
HRI = ΔHR ratio × 0.64 × e^(1.92 × ΔHR ratio)    # 男性
HRI = ΔHR ratio × 0.86 × e^(1.67 × ΔHR ratio)    # 女性

ΔHR ratio = (运动平均心率 - 静息心率) / (最大心率 - 静息心率)
```

示例：男性，静息心率 60，最大心率 190，运动平均心率 150，时长 45 分钟

```
ΔHR ratio = (150 - 60) / (190 - 60) = 0.692
HRI = 0.692 × 0.64 × e^(1.92 × 0.692) = 0.692 × 0.64 × 3.79 = 1.678
TRIMP = 45 × 1.678 = 75.5
```

### 简化 TRIMP (sRPE-TRIMP)

当缺少心率数据时，可用主观疲劳感知替代：

```
sRPE-TRIMP = 训练时长(分钟) × RPE(1-10 量表)
```

## 2. 心率区间定义

### 最大心率估算

```
经典公式: HRmax = 220 - 年龄
Tanaka 公式 (更准确): HRmax = 208 - 0.7 × 年龄
```

### Karvonen 储备心率法

```
目标心率 = 静息心率 + 强度百分比 × (最大心率 - 静息心率)
```

### 五区间划分

| 区间 | 名称 | %HRmax | %HRR (Karvonen) | 训练效果 |
|------|------|--------|------------------|----------|
| Z1 | 恢复区 | 50-60% | 40-50% | 主动恢复、热身冷身 |
| Z2 | 有氧基础区 | 60-70% | 50-60% | 脂肪燃烧、有氧基础建设 |
| Z3 | 有氧耐力区 | 70-80% | 60-70% | 提高有氧能力、乳酸阈值 |
| Z4 | 乳酸阈值区 | 80-90% | 70-85% | 提高乳酸阈值、速度耐力 |
| Z5 | 无氧极限区 | 90-100% | 85-100% | 最大摄氧量、爆发力 |

### 各区间推荐时间占比 (80/20 原则)

- Z1-Z2: 占总训练时间 75-80%
- Z3: 占 5-10%
- Z4-Z5: 占 10-20%

## 3. 急性:慢性训练负荷比 (ACWR)

### 计算方法

```
ACWR = 急性负荷(7天) / 慢性负荷(28天滚动平均)

急性负荷 = 近 7 天 TRIMP 总和 / 7
慢性负荷 = 近 28 天 TRIMP 总和 / 28
```

### 指数加权移动平均 (EWMA) 改进版

EWMA 方法能更好地反映训练负荷的时间衰减效应：

```
EWMA_today = Load_today × λ + (1 - λ) × EWMA_yesterday

λ_acute = 2 / (7 + 1) = 0.25
λ_chronic = 2 / (28 + 1) = 0.069

ACWR = EWMA_acute / EWMA_chronic
```

### ACWR 风险分区

| ACWR 范围 | 状态 | 建议 |
|-----------|------|------|
| < 0.8 | 训练不足 | 逐步增加训练量，每周增幅不超过 10% |
| 0.8 - 1.3 | 最佳区间 | 维持当前负荷节奏 |
| 1.3 - 1.5 | 警戒区 | 降低训练强度，增加恢复 |
| > 1.5 | 危险区 | 立即降低训练量，安排休息日 |

## 4. 恢复准备度评估

### 复合评分公式

```
恢复准备度 = f(HRV, 睡眠质量, 压力水平, Body Battery)
```

加权计算模型：

```
Recovery Score = w1 × HRV_score + w2 × Sleep_score + w3 × Stress_score + w4 × BB_score

默认权重:
  w1 (HRV)          = 0.30
  w2 (睡眠质量)      = 0.30
  w3 (压力水平)      = 0.20
  w4 (Body Battery)  = 0.20
```

### 各维度评分标准

**HRV 评分 (0-100)**:
- 与个人 30 天基线对比
- HRV > 基线 +10%: 90-100 分
- HRV 在基线 ±10%: 60-89 分
- HRV < 基线 -10%: 30-59 分
- HRV < 基线 -20%: 0-29 分

**睡眠质量评分 (0-100)**:
- 睡眠时长 ≥ 7.5h + 深睡占比 ≥ 20%: 85-100 分
- 睡眠时长 6.5-7.5h + 深睡占比 15-20%: 60-84 分
- 睡眠时长 5.5-6.5h 或 深睡占比 < 15%: 30-59 分
- 睡眠时长 < 5.5h: 0-29 分

**压力水平评分 (0-100, 反向)**:
- Garmin 压力值 0-25: 85-100 分 (低压力)
- Garmin 压力值 26-50: 60-84 分
- Garmin 压力值 51-75: 30-59 分
- Garmin 压力值 76-100: 0-29 分 (高压力)

**Body Battery 评分 (0-100)**:
- 直接使用 Garmin Body Battery 数值
- 晨起值 > 80: 优秀
- 晨起值 60-80: 良好
- 晨起值 40-60: 一般
- 晨起值 < 40: 疲劳

### 恢复准备度建议

| 综合得分 | 建议 |
|---------|------|
| 80-100 | 可进行高强度训练 (Z4-Z5) |
| 60-79 | 建议中等强度训练 (Z2-Z3) |
| 40-59 | 仅建议低强度恢复训练 (Z1-Z2) |
| 0-39 | 建议完全休息或极轻量活动 |

## 5. 周期化训练原则

### 渐进超负荷原则

```
每周训练量增幅 ≤ 10% (急性增幅上限)
每 3-4 周安排 1 周减量周 (负荷降至 60-70%)
```

### 超量补偿模型

```
训练刺激 → 疲劳 → 恢复 → 超量补偿 → 新基线

关键时间窗口:
  - 肌肉恢复: 24-72 小时
  - 神经系统恢复: 48-96 小时
  - 结缔组织恢复: 72-120 小时
```

### 周期化模型

**线性周期化 (适合初学者)**:
- 第 1-4 周: 基础期 — 高量低强度
- 第 5-8 周: 发展期 — 中量中强度
- 第 9-12 周: 强化期 — 低量高强度
- 第 13 周: 减量/测试周

**波动周期化 (适合进阶者)**:
- 在周内交替安排不同强度
- 周一: 高强度低量
- 周三: 中强度中量
- 周五: 低强度高量

**极化训练模型 (适合耐力运动员)**:
- 约 80% 训练在 Z1-Z2 (低强度)
- 约 20% 训练在 Z4-Z5 (高强度)
- 尽量避免 Z3 (中间灰色地带)

## 6. 运动类型专项建议

### 跑步

| 训练类型 | 配速参考 | 心率区间 | 每周频率 |
|---------|---------|---------|---------|
| 轻松跑 | 比赛配速 +60-90s/km | Z1-Z2 | 3-4 次 |
| 节奏跑 | 乳酸阈值配速 | Z3-Z4 | 1 次 |
| 间歇跑 | 比赛配速 -10-20s/km | Z4-Z5 | 1 次 |
| 长距离跑 | 轻松跑配速 | Z2 | 1 次 (周末) |
| 恢复跑 | 最慢配速 | Z1 | 1-2 次 |

**跑量建议**:
- 初跑者: 15-25 km/周
- 中级跑者: 30-50 km/周
- 进阶跑者: 50-80 km/周
- 精英跑者: 80-150 km/周

### 骑行

| 训练类型 | 功率参考 (%FTP) | 心率区间 | 时长 |
|---------|----------------|---------|------|
| 恢复骑 | < 55% FTP | Z1 | 30-60 min |
| 耐力骑 | 56-75% FTP | Z2 | 60-180 min |
| 甜区训练 | 84-97% FTP | Z3-Z4 | 20-60 min |
| 阈值训练 | 96-105% FTP | Z4 | 8-30 min |
| VO2max间歇 | 106-120% FTP | Z5 | 3-8 min × 组 |

### 游泳

| 训练类型 | 强度 | 组间休息 | 每周频率 |
|---------|------|---------|---------|
| 技术练习 | 低强度 | 充分 | 每次含 10-15 min |
| 有氧长划 | Z2 | 10-15s/100m | 2-3 次 |
| 阈值训练 | Z3-Z4 | 15-30s/100m | 1-2 次 |
| 速度间歇 | Z5 | 完全恢复 | 1 次 |

### 力量训练

| 目标 | 负重 (%1RM) | 次数/组 | 组数 | 组间休息 |
|------|------------|--------|------|---------|
| 肌肉耐力 | 40-60% | 15-20 | 2-3 | 30-60s |
| 肌肥大 | 60-80% | 8-12 | 3-4 | 60-90s |
| 最大力量 | 80-95% | 3-6 | 4-6 | 2-5 min |
| 爆发力 | 30-60% | 3-6 | 3-5 | 2-3 min |

### HIIT (高强度间歇训练)

| 模式 | 工作时间 | 休息时间 | 工休比 | 总组数 |
|------|---------|---------|--------|-------|
| Tabata | 20s | 10s | 2:1 | 8 |
| 短间歇 | 30s | 30s | 1:1 | 8-12 |
| 中间歇 | 60s | 60s | 1:1 | 6-8 |
| 长间歇 | 3-5 min | 3-5 min | 1:1 | 4-6 |

**HIIT 频率限制**: 每周不超过 2-3 次，间隔至少 48 小时。

## 7. 环境调整因子

### 温度调整

| 温度范围 | 调整系数 | 建议 |
|---------|---------|------|
| < 0°C | ×0.90 | 延长热身时间，注意保暖 |
| 0-10°C | ×0.95 | 适当增加热身 |
| 10-20°C | ×1.00 | 理想温度范围 |
| 20-25°C | ×1.00 | 正常训练 |
| 25-30°C | ×0.90 | 降低强度，增加补水 |
| 30-35°C | ×0.80 | 显著降低强度和时长 |
| > 35°C | ×0.60-0.70 | 建议室内训练或取消 |

热习服需要 10-14 天逐步适应，每天增加 5-10% 热环境暴露时间。

### 海拔调整

| 海拔范围 | 调整系数 | 影响 |
|---------|---------|------|
| < 1000m | ×1.00 | 无显著影响 |
| 1000-1500m | ×0.95 | 轻微影响，2-3 天适应 |
| 1500-2500m | ×0.85-0.90 | 中等影响，5-7 天适应 |
| 2500-3500m | ×0.75-0.85 | 显著影响，7-14 天适应 |
| > 3500m | ×0.60-0.75 | 严重影响，需专业指导 |

### 空气质量 (AQI) 调整

| AQI 范围 | 等级 | 调整建议 |
|---------|------|---------|
| 0-50 | 优 | 正常户外运动 |
| 51-100 | 良 | 正常训练，敏感人群注意 |
| 101-150 | 轻度污染 | 减少户外高强度运动 |
| 151-200 | 中度污染 | 避免户外运动，改室内 |
| 201-300 | 重度污染 | 禁止户外运动 |
| > 300 | 严重污染 | 减少一切户外活动 |

## 8. 过度训练综合征指标

### 早期预警信号

**生理指标**:
- 静息心率持续升高 > 5 bpm (连续 3 天以上)
- HRV 持续低于个人基线 15% 以上
- 运动后心率恢复变慢 (1 分钟恢复率下降)
- 最大心率无法达到以往水平
- 持续性疲劳、肌肉酸痛超过 72 小时

**训练表现指标**:
- 同等配速下心率显著偏高
- 同等心率下配速明显下降
- 力量训练重量/次数持续下降
- 训练意愿明显降低

**身体信号**:
- 睡眠质量持续下降
- 免疫力下降 (频繁感冒)
- 食欲变化 (下降或异常增加)
- 情绪波动增大 (易怒、焦虑)
- 体重异常变化

### 过度训练风险评估评分

```
过度训练风险 = Σ(指标得分 × 权重)

权重分配:
  静息心率异常: 0.20
  HRV 异常: 0.20
  ACWR > 1.5: 0.20
  睡眠质量下降: 0.15
  表现持续下降: 0.15
  主观疲劳度: 0.10
```

| 风险得分 | 等级 | 建议 |
|---------|------|------|
| 0-30 | 低风险 | 正常训练 |
| 31-50 | 中低风险 | 关注恢复，适当减量 |
| 51-70 | 中高风险 | 减量 50%，增加休息日 |
| 71-100 | 高风险 | 停训 3-7 天，就医评估 |

## 9. 伤病风险评估

### 基于 ACWR 的伤病风险模型

```
伤病风险指数 = f(ACWR, 训练史, 既往伤病, 年龄)
```

**ACWR 与伤病风险关系**:

| ACWR | 相对伤病风险 (参考值) |
|------|-------------------|
| 0.5-0.8 | 0.8-1.0 (基线) |
| 0.8-1.0 | 0.7-0.8 (最低风险) |
| 1.0-1.3 | 0.8-1.2 |
| 1.3-1.5 | 1.5-2.5 |
| 1.5-2.0 | 2.0-4.0 |
| > 2.0 | > 4.0 |

### 伤病风险修正因子

| 因素 | 修正系数 |
|------|---------|
| 年龄 > 40 | ×1.2 |
| 年龄 > 50 | ×1.4 |
| 6 个月内有伤病史 | ×1.5 |
| 训练年限 < 1 年 | ×1.3 |
| BMI > 30 | ×1.3 |
| 睡眠不足 (< 6h/天) | ×1.4 |

### 预防建议

- ACWR 维持在 0.8-1.3 的安全区间
- 每周训练量增幅不超过 10%
- 每次训练包含充分热身 (10-15 min) 和放松 (5-10 min)
- 每周至少安排 1 个完全休息日
- 交叉训练降低重复性劳损风险
- 关注身体反馈，出现疼痛立即调整
