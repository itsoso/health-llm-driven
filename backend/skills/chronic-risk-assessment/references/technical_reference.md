# 慢病风险评估 - 技术参考

## 1. Framingham 心血管风险评分公式

### 1.1 概述
Framingham 10年心血管风险评分基于 Framingham Heart Study 队列数据，预测 10 年内发生心血管事件（心肌梗死、脑卒中、心血管死亡）的概率。

| 35-39 | 2 |
| 40-44 | 5 |
| 45-49 | 7 |
| 50-54 | 8 |
| 55-59 | 10 |
| 60-64 | 11 |
| 65-69 | 12 |
| 70-74 | 14 |

**女性积分表：**

- 不吸烟：0 分

**糖尿病：**
- 男性 +3 分，女性 +4 分

### 1.3 积分→概率转换

总积分越高，10 年风险越高。本系统使用简化的对数回归模型：
- 男性：P = 1 - 0.88936^exp(score × 0.04826)
- 女性：P = 1 - 0.95012^exp(score × 0.03352)

### 1.4 可穿戴数据调整因子

基于观察性研究的辅助调整（非 Framingham 原始公式）：

| 指标 | 调整规则 | 证据来源 |
|------|----------|----------|
| 静息心率 >75 bpm | +1% 绝对风险 | HUNT Study (Nauman 2011) |
| 静息心率 <60 bpm | -0.5% 绝对风险 | 同上 |
| HRV (SDNN) <50ms | +0.5% 绝对风险 | Thayer 2010 meta-analysis |
| 每周运动 ≥150min | -1% 绝对风险 | AHA 2018 指南 |
| 每周运动 <60min | +0.5% 绝对风险 | 同上 |

### 1.5 置信区间计算

采用 Framingham 发表的标准误差，95% CI 约为风险估计值 ±20%：
- CI_lower = max(0, score × 0.8)
- CI_upper = min(100, score × 1.2)

## 2. 代谢综合征 IDF 标准

### 2.1 诊断标准（IDF 2005 共识）

满足以下 5 项中的 **3 项或以上** 即诊断代谢综合征：

1. **中心性肥胖**（腰围）
   - 亚洲男性 ≥90 cm
   - 亚洲女性 ≥80 cm
   - 如无腰围数据，BMI ≥25 可替代参考（非标准）

2. **血压升高**
   - 收缩压 ≥130 mmHg 或 舒张压 ≥85 mmHg
   - 或正在接受高血压治疗

3. **空腹血糖升高**
   - 空腹血糖 ≥5.6 mmol/L（100 mg/dL）
   - 或已诊断 2 型糖尿病

4. **HDL 胆固醇降低**
   - 男性 <1.03 mmol/L（40 mg/dL）
   - 女性 <1.29 mmol/L（50 mg/dL）

5. **甘油三酯升高**
   - ≥1.7 mmol/L（150 mg/dL）

### 2.2 亚洲人群特殊考虑
- 腰围阈值使用亚太标准（低于西方标准）
- BMI 分类使用 WHO 亚太标准：正常 <23，超重 23-24.9，肥胖 ≥25

## 3. 年龄/性别分层策略

### 3.1 年龄计算
从 User.birth_date 计算当前年龄：
```
age = (today - birth_date).days / 365.25
```

### 3.2 性别处理
- User.gender 字段：男/女
- Framingham 使用性别特异性积分表
- 代谢综合征腰围/HDL 阈值按性别调整
- 性别缺失时按男性（更保守）处理，并标注

### 3.3 年龄范围限制
- Framingham 适用 30-74 岁
- <30 岁：返回评估但标注"低龄群体，Framingham 外推不可靠"
- >74 岁：返回评估但标注"高龄群体，模型准确度降低"

## 4. 90 天趋势分析

### 4.1 方法
对近 90 天的关键指标进行简单线性回归：
- 血压（收缩压）
- 体重/BMI
- 血脂（如有多次记录）
- 静息心率（Garmin 日数据）

### 4.2 趋势判定
- 斜率 >0 且 p <0.05：上升趋势
- 斜率 <0 且 p <0.05：下降趋势
- 其他：稳定/无显著趋势

### 4.3 限制
- 需要至少 2 个数据点
- 血脂等实验室指标通常数据点少，趋势判断不可靠
- 仅供参考趋势方向，不作为定量预测
