# 睡眠深度分析 - 技术参考

## 睡眠架构（Sleep Architecture）

### 睡眠阶段定义

| 阶段 | 英文 | 脑电波特征 | 功能 |
|------|------|-----------|------|
| 浅睡眠 | Light Sleep (N1+N2) | Theta波、睡眠纺锤波 | 记忆巩固、过渡阶段 |
| 深睡眠 | Deep Sleep (N3) | Delta波（慢波睡眠） | 身体修复、生长激素分泌、免疫增强 |
| 快速眼动睡眠 | REM Sleep | 混合频率、快速眼球运动 | 情绪调节、学习记忆、创造力 |
| 清醒 | Awake | Alpha/Beta波 | 正常觉醒 |

### 各年龄段正常睡眠架构比例

| 年龄段 | 深睡眠 % | 浅睡眠 % | REM % | 清醒 % |
|--------|---------|---------|-------|--------|
| 18-25岁 | 20-25% | 45-55% | 20-25% | 5% |
| 26-35岁 | 17-22% | 50-55% | 20-25% | 5-8% |
| 36-45岁 | 15-20% | 50-60% | 18-22% | 5-10% |
| 46-55岁 | 12-18% | 55-60% | 17-20% | 8-12% |
| 56-65岁 | 10-15% | 55-65% | 15-18% | 10-15% |
| 65岁以上 | 5-12% | 60-70% | 13-18% | 12-20% |

**关键趋势**：深睡眠随年龄递减约每十年下降2-3个百分点。这是正常生理现象，不必过度焦虑。

### Garmin 设备测量原理

Garmin 通过以下传感器估算睡眠阶段：
- **加速度计**：检测身体活动和微动
- **光学心率传感器**：测量心率和HRV
- **血氧传感器**（部分型号）：SpO2变化辅助判断

准确度：与多导睡眠图（PSG）对比，总体一致率约 80%。深睡眠可能偏差 10-15 分钟。

## HRV 与睡眠恢复

### 睡眠期间 HRV 变化规律

1. **入睡后 HRV 上升**：副交感神经激活，心率变异性增大 → 表示身体进入恢复模式
2. **深睡眠阶段 HRV 最高**：慢波睡眠期间副交感占优，HRV达到峰值
3. **REM 阶段 HRV 下降**：交感神经短暂激活，心率变异性降低
4. **觉醒前 HRV 下降**：交感神经逐渐激活，准备觉醒

### HRV 恢复质量评估

| HRV 指标 | 良好恢复 | 一般恢复 | 较差恢复 |
|----------|---------|---------|---------|
| 睡眠 HRV vs 日间 HRV | 高出 20%+ | 高出 10-20% | 高出 <10% |
| HRV 7天趋势 | 稳定或上升 | 波动 | 持续下降 |
| 结合 Body Battery | 充电 >60 | 充电 30-60 | 充电 <30 |

### Garmin HRV 状态含义

- **balanced（平衡）**：HRV 在个人正常范围内
- **unbalanced（不平衡）**：HRV 偏离正常范围（通常偏低）
- **low（偏低）**：HRV 显著低于个人基线，可能与压力、疾病、过度训练相关

## 睡眠债务（Sleep Debt）

### 计算模型

```
单日债务 = 推荐时长 - 实际睡眠时长
累积债务 = Σ(单日债务)    // 仅累计负值（不足部分）
```

### 债务严重程度分级

| 累积债务 | 严重程度 | 影响 |
|---------|---------|------|
| < 2小时 | 无/轻微 | 可忽略，正常波动范围 |
| 2-5小时 | 轻度 | 白天可能偶尔困倦 |
| 5-10小时 | 中度 | 注意力、反应速度下降 |
| > 10小时 | 严重 | 认知功能显著受损，情绪波动 |

### 恢复估算

- 轻度债务：额外睡1-2晚即可恢复
- 中度债务：需要3-5晚逐步补回（每晚多睡1-1.5小时）
- 严重债务：需要1-2周调整，不建议单次长睡弥补
- **注意**：睡眠债务恢复是非线性的，约2/3可在一周内恢复，剩余需要更长时间

## 昼夜节律（Circadian Rhythm）

### 睡眠一致性

规律的入睡/起床时间对睡眠质量的影响大于总时长。

| 入睡时间变异（标准差） | 评估 |
|----------------------|------|
| < 30分钟 | 非常规律 |
| 30-60分钟 | 较规律 |
| 60-90分钟 | 不够规律 |
| > 90分钟 | 很不规律，可能影响昼夜节律 |

### 最佳睡眠窗口

- 大多数成年人的理想入睡时间：22:00 - 23:30
- 早于 21:00 或晚于 01:00 可能偏离自然节律
- 个体差异大，"猫头鹰型"和"云雀型"的最佳窗口不同

## 环境因素与睡眠

### 温度

| 室温 | 对睡眠的影响 |
|------|------------|
| 16-19°C | 最佳睡眠温度范围 |
| 20-22°C | 可接受 |
| > 25°C | 深睡眠减少，觉醒增加 |
| < 15°C | 可能因寒冷觉醒 |

### 空气质量（AQI）

| AQI | 对睡眠的影响 |
|-----|------------|
| 0-50 | 优，无影响 |
| 51-100 | 良，轻微影响（敏感人群） |
| 101-150 | 轻度污染，可能增加觉醒次数 |
| > 150 | 中度及以上，建议关窗+空气净化器 |

### 噪音

| 分贝 | 对睡眠的影响 |
|------|------------|
| < 30 dB | 安静，理想环境 |
| 30-40 dB | 轻微背景噪音，大多数人可适应 |
| 40-55 dB | 可能延长入睡时间 |
| > 55 dB | 显著干扰睡眠，增加觉醒 |
