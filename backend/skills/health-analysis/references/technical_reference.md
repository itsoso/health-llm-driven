# 健康分析技术参考手册

本文档定义健康分析的五大维度、评估逻辑、跨维度协同效应及数据质量要求，供 AI 分析引擎参考。

---

## 一、五维度分析框架

### 1. 心血管维度 (cardiovascular)

**核心指标**

| 指标 | 数据来源 | 正常参考范围 | 单位 |
|------|----------|-------------|------|
| 静息心率 (RHR) | Garmin/手动 | 60-100（运动人群可低至 40） | bpm |
| 心率变异性 (HRV, RMSSD) | Garmin | 因年龄差异大，见阈值文档 | ms |
| 收缩压 (SBP) | 手动记录 | < 120 | mmHg |
| 舒张压 (DBP) | 手动记录 | < 80 | mmHg |
| 血氧饱和度 (SpO2) | Garmin | 95-100 | % |

**关注模式**

- RHR 持续上升趋势（7 日均值比基线高 5+ bpm）：可能提示过度训练、感染前兆、压力过大
- HRV 持续走低（7 日均值低于个人基线 15%+）：自主神经恢复不足
- 血压晨峰现象：晨起收缩压比夜间高 35+ mmHg，心血管事件风险增加
- SpO2 夜间持续低于 93%：需排查睡眠呼吸暂停

**个人基线计算**

- 取最近 30 天数据的中位数作为个人基线
- 新用户数据不足 14 天时，使用人群参考值
- 基线每 30 天滚动更新一次

### 2. 代谢维度 (metabolic)

**核心指标**

| 指标 | 数据来源 | 正常参考范围（中国标准） | 单位 |
|------|----------|----------------------|------|
| BMI | 体重/身高计算 | 18.5-23.9 | kg/m2 |
| 体重变化率 | 体重记录 | 周变化 < 1% | % |
| 体脂率 | 体脂秤/手动 | 男 15-20%，女 20-25% | % |
| 空腹血糖 | 体检/手动 | 3.9-6.1 | mmol/L |
| 总胆固醇 | 体检 | < 5.2 | mmol/L |
| 低密度脂蛋白 (LDL) | 体检 | < 3.4 | mmol/L |
| 高密度脂蛋白 (HDL) | 体检 | 男 > 1.0，女 > 1.3 | mmol/L |
| 甘油三酯 (TG) | 体检 | < 1.7 | mmol/L |
| 糖化血红蛋白 (HbA1c) | 体检 | < 6.0 | % |

**关注模式**

- 体重月增幅 > 2kg 且体脂率上升：脂肪增长而非肌肉增长
- BMI 正常但体脂率偏高（男 > 25%，女 > 30%）：隐性肥胖
- LDL/HDL 比值 > 3.0：动脉粥样硬化风险升高
- 空腹血糖 6.1-7.0：糖尿病前期，需加强监测

**体重趋势分析**

- 使用指数加权移动平均 (EWMA, alpha=0.1) 平滑体重波动
- 日内波动 1-2kg 属正常（水分、进食），关注 7 日趋势而非单日数值

### 3. 睡眠与恢复维度 (sleep_recovery)

**核心指标**

| 指标 | 数据来源 | 推荐范围 | 单位 |
|------|----------|---------|------|
| 总睡眠时长 | Garmin | 7-9 小时（成人） | 小时 |
| 深睡比例 | Garmin | 15-25% | % |
| REM 比例 | Garmin | 20-25% | % |
| 睡眠效率 | 计算值 | > 85% | % |
| 入睡时间 | Garmin | < 20 分钟 | 分钟 |
| 觉醒次数 | Garmin | < 3 次 | 次 |
| Garmin Body Battery | Garmin | 晨起 > 60 | 分 |
| 压力评分 | Garmin | 日均 < 40 | 分 |

**关注模式**

- 深睡比例连续 3 天 < 10%：恢复质量堪忧，建议检查环境因素
- 入睡时间 > 30 分钟：入睡困难，可能与咖啡因、屏幕时间、焦虑有关
- Body Battery 晨起 < 30：严重恢复不足，建议当日减少训练强度
- 睡眠中点（入睡与起床中间时刻）日间波动 > 2 小时：社交时差，影响昼夜节律

**睡眠评分计算逻辑**

```
睡眠评分 = 时长得分(40%) + 深睡得分(25%) + REM得分(20%) + 效率得分(15%)

时长得分：
  7-9h = 100, 6-7h = 70, 5-6h = 40, <5h = 10, >10h = 60

深睡得分：
  15-25% = 100, 10-15% = 60, <10% = 20, >30% = 80

REM得分：
  20-25% = 100, 15-20% = 60, <15% = 20, >30% = 80
```

### 4. 体能维度 (fitness)

**核心指标**

| 指标 | 数据来源 | 参考标准 | 单位 |
|------|----------|---------|------|
| 日步数 | Garmin | > 8000 | 步 |
| 周运动时长 | 运动记录 | > 150 分钟中等强度 | 分钟 |
| 最大摄氧量 (VO2Max) | Garmin | 因年龄性别差异大 | mL/kg/min |
| 周运动频次 | 运动记录 | 3-5 次 | 次/周 |
| 训练负荷 (TRIMP) | 心率数据计算 | 因人而异 | 任意单位 |
| 运动强度分布 | 心率区间 | 80/20 原则 | % |

**关注模式**

- 日步数连续 3 天 < 3000：久坐警告
- 周运动时长 < 75 分钟：未达到 WHO 最低推荐量
- VO2Max 3 个月内下降 > 3 mL/kg/min：体能显著退步
- 高强度训练占比 > 30%：过度训练风险（推荐 80% 低强度 + 20% 高强度）
- 连续高负荷训练 > 3 天无休息日：需安排恢复

**运动强度区间定义（基于最大心率）**

| 区间 | 心率范围 | 描述 |
|------|---------|------|
| Zone 1 | 50-60% HRmax | 热身/恢复 |
| Zone 2 | 60-70% HRmax | 有氧基础 |
| Zone 3 | 70-80% HRmax | 有氧耐力 |
| Zone 4 | 80-90% HRmax | 乳酸阈值 |
| Zone 5 | 90-100% HRmax | 无氧/冲刺 |

最大心率估算：HRmax = 220 - 年龄（粗略），更精确使用 Tanaka 公式：HRmax = 208 - 0.7 x 年龄

### 5. 营养维度 (nutrition)

**核心指标**

| 指标 | 数据来源 | 推荐范围 | 单位 |
|------|----------|---------|------|
| 日饮水量 | 手动记录 | 1500-2500 | mL |
| 日热量摄入 | 饮食记录 | 因人而异 (BMR x 活动系数) | kcal |
| 蛋白质摄入 | 饮食记录 | 1.0-1.6 g/kg 体重 | g |
| 膳食纤维 | 饮食记录 | 25-35 | g |
| 餐次规律性 | 饮食记录时间 | 三餐时间波动 < 1 小时 | - |
| 补剂依从性 | 补剂记录 | > 80% | % |

**关注模式**

- 日饮水量 < 1000mL：脱水风险
- 蛋白质摄入 < 0.8g/kg：蛋白质不足，影响肌肉恢复
- 连续 3 天无饮食记录：数据缺失，无法评估
- 晚餐时间 > 21:00：可能影响睡眠质量
- 补剂记录中断 > 3 天：依从性下降提醒

## 二、严重程度决策树

### 判定流程

```
对每个维度的每个指标：

1. 取最近 N 天数据（N 由指标类型决定）
2. 计算趋势方向（上升/稳定/下降）
3. 与参考范围比对

判定规则：
├── 指标在正常范围内 且 趋势稳定
│   └── 正常 (normal)
├── 指标在正常范围内 但 趋势朝不利方向
│   └── 注意 (caution)
├── 指标轻度偏离正常范围（偏离 < 20%）
│   ├── 持续 < 3 天 → 注意 (caution)
│   └── 持续 >= 3 天 → 警告 (warning)
├── 指标显著偏离正常范围（偏离 >= 20%）
│   └── 警告 (warning)
└── 多个维度同时异常
    └── 提升整体严重等级
```

### 严重等级定义

| 等级 | 标识 | 含义 | 建议行动 |
|------|------|------|---------|
| 正常 | normal | 指标正常，趋势良好 | 保持当前习惯 |
| 注意 | caution | 有轻微偏离或不利趋势 | 关注并适当调整 |
| 警告 | warning | 指标明显异常或持续恶化 | 建议尽快干预或就医 |

### 升级规则

- 同一维度内 2+ 个 caution → 该维度升级为 warning
- 3+ 个维度出现 caution → 整体健康评估升级为 warning
- 任何涉及安全阈值的指标（如 SpO2 < 90%、SBP > 180）→ 直接 warning

## 三、跨维度协同效应

跨维度分析是本系统的核心差异化能力。以下为已验证的协同模式：

### 3.1 过度训练综合征检测

**触发条件**（需同时满足至少 3 项）：

- 睡眠维度：HRV 低于基线 20%+
- 睡眠维度：深睡比例 < 10%
- 体能维度：近 7 天训练负荷高于月均 30%+
- 心血管维度：RHR 高于基线 5+ bpm
- 营养维度：蛋白质摄入低于推荐量

**输出**：warning 级别，建议减量恢复 2-3 天

### 3.2 代谢综合征风险

**触发条件**（满足 3 项及以上）：

- 代谢维度：BMI > 25 或腰围男 > 90cm / 女 > 85cm
- 代谢维度：TG > 1.7 mmol/L
- 代谢维度：HDL 男 < 1.0 / 女 < 1.3 mmol/L
- 心血管维度：血压 > 130/85 mmHg
- 代谢维度：空腹血糖 > 6.1 mmol/L

**输出**：warning 级别，建议就医筛查并调整生活方式

### 3.3 睡眠-运动失衡

**触发条件**：

- 睡眠维度：总时长 < 6 小时 连续 3 天
- 体能维度：期间有中高强度训练

**输出**：caution 级别，建议优先补充睡眠，降低训练强度

### 3.4 压力-代谢恶性循环

**触发条件**：

- 睡眠维度：Garmin 压力评分日均 > 50 连续 5 天
- 代谢维度：体重周增 > 1kg
- 营养维度：进餐时间不规律（波动 > 2 小时）

**输出**：caution 级别，建议压力管理 + 规律作息

### 3.5 心血管-体能协同预警

**触发条件**：

- 心血管维度：RHR 趋势上升 + HRV 趋势下降
- 体能维度：VO2Max 下降趋势
- 持续 > 14 天

**输出**：warning 级别，建议进行心肺功能检查

### 3.6 营养-恢复关联

**触发条件**：

- 营养维度：日饮水量 < 1200mL
- 营养维度：蛋白质摄入 < 0.8g/kg
- 睡眠维度：Body Battery 晨起 < 40

**输出**：caution 级别，建议增加水分和蛋白质摄入以改善恢复

## 四、数据质量要求

### 最低数据天数

| 分析类型 | 最低天数 | 推荐天数 | 说明 |
|----------|---------|---------|------|
| 单日快照 | 1 天 | - | 仅展示当日数据，不做趋势判断 |
| 短期趋势 | 3 天 | 7 天 | 可识别急性变化 |
| 中期趋势 | 7 天 | 14 天 | 可识别习惯性模式 |
| 长期趋势 | 14 天 | 30 天 | 可建立个人基线 |
| 跨维度协同 | 7 天 | 14 天 | 需多维度数据同时存在 |

### 数据完整度分级

```
优秀 (A)：覆盖率 > 90%，可进行全维度分析
良好 (B)：覆盖率 70-90%，分析结果可靠，部分维度可能缺失
及格 (C)：覆盖率 50-70%，仅做参考，需提示数据不足
不足 (D)：覆盖率 < 50%，仅展示已有数据，不做趋势和协同分析
```

### 缺失值处理策略

| 场景 | 处理方式 |
|------|---------|
| 单日数据缺失（如某天忘戴手表） | 使用前后日均值插值，标记为估算值 |
| 连续 3 天以上缺失 | 不做插值，该时段标记为数据空白 |
| 某维度完全无数据 | 跳过该维度分析，报告中说明 |
| 设备数据异常（如心率 250bpm） | 使用 3-sigma 规则剔除异常值 |
| 手动记录与设备记录冲突 | 优先使用设备记录，手动记录作为补充 |

### 数据新鲜度

- 超过 7 天无新数据：分析结果标记为"数据过期"
- 超过 30 天无新数据：不生成分析报告，仅提示用户同步数据

## 五、年龄与性别分层

### 年龄分组

| 组别 | 年龄范围 | 特殊考量 |
|------|---------|---------|
| 青年组 | 18-35 岁 | 运动耐受度高，恢复快，可接受更高训练负荷 |
| 中年组 | 36-55 岁 | 关注代谢指标变化，训练恢复时间延长，心血管风险开始上升 |
| 中老年组 | 56-70 岁 | 重点关注血压、血糖、骨密度，运动以中低强度为主 |
| 老年组 | 70 岁以上 | 安全第一，关注跌倒风险，用药交互，运动以维持功能为主 |

### 性别差异调整

| 指标 | 男性调整 | 女性调整 |
|------|---------|---------|
| 体脂率参考范围 | 15-20% 正常 | 20-25% 正常 |
| HDL 阈值 | > 1.0 mmol/L | > 1.3 mmol/L |
| 铁蛋白参考值 | 30-400 ng/mL | 13-150 ng/mL |
| BMR 估算 | Mifflin-St Jeor 男性公式 | Mifflin-St Jeor 女性公式 |
| VO2Max 评级 | 使用男性年龄分层表 | 使用女性年龄分层表 |

**女性特殊周期考量**

- 月经期间：RHR 和 HRV 会有生理性波动，不应作为异常标记
- 经前期（黄体期后半段）：体重可能增加 1-2kg（水分滞留），属正常现象
- 如用户开启了经期跟踪功能，分析时自动纳入周期因素校正

### BMR 估算公式 (Mifflin-St Jeor)

```
男性：BMR = 10 x 体重(kg) + 6.25 x 身高(cm) - 5 x 年龄 - 5
女性：BMR = 10 x 体重(kg) + 6.25 x 身高(cm) - 5 x 年龄 - 161

活动系数：
  久坐 (sedentary)：BMR x 1.2
  轻度活动：BMR x 1.375
  中度活动：BMR x 1.55
  高度活动：BMR x 1.725
  极高活动：BMR x 1.9
```

## 六、分析输出格式规范

### 结构化输出

每次分析输出应包含：

1. **总体评估**：综合健康状态一句话总结
2. **各维度评分**：五个维度各 0-100 分
3. **发现列表**：按严重程度排序的具体发现
4. **跨维度洞察**：协同效应检测结果
5. **行动建议**：按优先级排列的具体可执行建议（限 3-5 条）
6. **数据质量声明**：数据覆盖率和可信度说明

### 展示优先级

1. warning 级别发现优先展示
2. 跨维度协同发现优先于单维度发现
3. 可执行的建议优先于信息性说明
4. 趋势变化优先于绝对值判断
