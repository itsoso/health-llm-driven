# 膳食补充剂顾问 — 技术参考手册

## 1. 基因-补充剂交互决策矩阵

### 1.1 已纳入基因变异

| 基因 | 变异位点 | 风险基因型 | 补充剂影响 | 建议调整 |
|------|----------|-----------|-----------|---------|
| MTHFR | C677T | TT 纯合 | 叶酸代谢效率降低约 70% | 使用甲基叶酸（5-MTHF）400-800μg，避免合成叶酸 |
| MTHFR | A1298C | CC 纯合 | 叶酸代谢效率降低约 30-40% | 优先甲基叶酸，剂量可适当降低 |
| VDR | FokI / BsmI / TaqI | TT（FokI） | 维生素 D 受体活性降低 | 维生素 D3 剂量提升至 2000-4000 IU/天，配合维生素 K2 |
| ALDH2 | rs671 | GA/AA | 乙醛脱氢酶活性缺失 | 避免含酒精补充剂；增加 NAC、硫辛酸辅助肝脏解毒 |
| CYP2C19 | *2/*3 | 慢代谢型 | 影响多种药物和植物提取物代谢 | 降低姜黄素、水飞蓟素等需 CYP2C19 代谢的补充剂剂量 |

### 1.2 扩展基因变异

| 基因 | 变异位点 | 风险基因型 | 功能影响 | 补充剂建议 |
|------|----------|-----------|---------|-----------|
| COMT | Val158Met (rs4680) | Met/Met（慢代谢） | 儿茶酚胺分解减慢，对刺激性物质敏感 | 避免高剂量绿茶提取物（EGCG）；镁、SAMe 需谨慎；可受益于甲基供体适量补充 |
| COMT | Val158Met (rs4680) | Val/Val（快代谢） | 儿茶酚胺快速清除 | 可耐受较高剂量绿茶提取物；可能需要更多 SAMe 和甲基 B 族 |
| SOD2 | Ala16Val (rs4880) | Val/Val | 锰超氧化物歧化酶活性降低，氧化应激增加 | 增加抗氧化剂：辅酶 Q10（100-200mg）、硫辛酸（300-600mg）、维生素 C（500-1000mg） |
| SOD2 | Ala16Val (rs4880) | Ala/Ala | 线粒体 ROS 信号过强 | 避免超高剂量抗氧化剂（可能干扰细胞信号），适量补充即可 |
| GSTP1 | Ile105Val (rs1695) | Val/Val | 谷胱甘肽 S-转移酶活性改变，解毒能力下降 | 增加 NAC（600-1200mg/天）、硫辛酸；多摄入十字花科蔬菜提取物（萝卜硫素） |
| APOE | ε2/ε3/ε4 | ε4/ε4 | 阿尔茨海默风险升高，脂质代谢异常 | 增加 DHA（至少 1000mg/天）；避免高剂量铁剂；增加磷脂酰丝氨酸；姜黄素可能有益 |
| APOE | ε2/ε3/ε4 | ε2/ε2 | 甘油三酯偏高风险 | Omega-3 EPA 优先（1000-2000mg）；减少高脂肪来源的补充剂 |
| FTO | rs9939609 | AA | 肥胖风险增加，饱腹感信号减弱 | 绿茶提取物（EGCG 300-500mg）可能改善脂肪代谢；铬（200-400μg）辅助血糖控制 |
| TCF7L2 | rs7903146 | TT | 2 型糖尿病风险显著增加 | 铬（200-400μg吡啶甲酸铬）；肉桂提取物（500mg）；镁（300-400mg）；小檗碱需评估 |

### 1.3 多基因联合评估

当用户存在多个风险变异时，按以下优先级处理：

1. **安全性优先**：先排除药物-补充剂交互风险
2. **叠加效应**：MTHFR + COMT 联合影响甲基化通路，需整体规划甲基供体
3. **拮抗检查**：SOD2 Ala/Ala + 高剂量抗氧化剂可能适得其反
4. **代谢通路完整性**：CYP2C19 慢代谢 + GSTP1 变异 = 需全面降低植物提取物剂量

## 2. 补充剂服用时间优化框架

### 2.1 时间窗口分类

| 服用时间 | 适用补充剂 | 原理 |
|---------|-----------|------|
| **晨起空腹** | 益生菌、铁剂（与维 C 同服） | 胃酸最低时益生菌存活率最高；铁剂空腹吸收率提升 40-60% |
| **早餐随餐** | 多维、B 族维生素、辅酶 Q10、姜黄素 | 脂溶性成分需脂肪辅助吸收；B 族空腹可能引起恶心 |
| **午餐随餐** | Omega-3（EPA/DHA）、维生素 D3+K2、维生素 E | 午餐通常含脂肪，脂溶性成分吸收最佳 |
| **下午（14:00-16:00）** | 镁（如需提神则选苏糖酸镁） | 避免与钙剂同时服用（竞争吸收） |
| **晚餐随餐** | 叶黄素、虾青素 | 脂溶性类胡萝卜素需脂肪辅助 |
| **睡前（30-60分钟）** | 甘氨酸镁/苏糖酸镁、GABA、褪黑素、磷脂酰丝氨酸 | 促进放松和睡眠质量 |

### 2.2 间隔规则

- **钙与铁**：间隔至少 2 小时（竞争二价金属转运体 DMT1）
- **钙与甲状腺药物**：间隔至少 4 小时
- **锌与铜**：长期高剂量锌（>40mg）需补充铜（1-2mg）
- **铁与绿茶/咖啡**：间隔至少 1 小时（多酚螯合铁）
- **益生菌与抗生素**：间隔至少 2 小时

## 3. 药物-补充剂交互检查协议

### 3.1 高风险交互（必须警告）

| 药物类别 | 补充剂 | 交互类型 | 风险等级 |
|---------|--------|---------|---------|
| 华法林/抗凝药 | 维生素 K、鱼油、大蒜提取物、银杏 | 增强或拮抗抗凝效果 | **严重** |
| 他汀类降脂药 | 辅酶 Q10（建议补充）、红曲米（禁止同服） | 红曲米含洛伐他汀，叠加肌病风险 | **严重** |
| SSRI 抗抑郁药 | 5-HTP、圣约翰草、SAMe | 血清素综合征风险 | **严重** |
| 降压药（ACEi/ARB） | 钾补充剂 | 高钾血症 | **严重** |
| 甲状腺激素（左旋甲状腺素） | 钙、铁、大豆异黄酮 | 降低药物吸收 | **中度** |
| 糖尿病药物（二甲双胍） | 维生素 B12（建议补充）、铬 | 二甲双胍降低 B12 吸收；铬可能增强降糖效果 | **中度** |
| 免疫抑制剂 | 紫锥花、灵芝、黄芪 | 增强免疫可能拮抗药效 | **中度** |
| 口服避孕药 | 维生素 B6、叶酸、镁（建议补充） | 避孕药消耗这些营养素 | **提示** |

### 3.2 检查流程

1. 获取用户当前用药列表
2. 对每种药物查询交互数据库
3. 按风险等级排序：严重 > 中度 > 提示
4. 严重级别交互：必须提醒用户咨询医生，不得自行调整
5. 中度级别：给出建议但标注"请与医生确认"
6. 提示级别：作为知识补充告知用户

## 4. 补充剂组合规则

### 4.1 协同组合（推荐搭配）

| 组合 | 协同机制 | 建议 |
|------|---------|------|
| 维生素 D3 + K2（MK-7） | K2 引导钙沉积到骨骼而非血管 | D3:K2 比例约 1000IU:100μg |
| 铁 + 维生素 C | 维生素 C 将三价铁还原为更易吸收的二价铁 | 铁剂配 200-500mg 维 C |
| 镁 + 维生素 B6 | B6 促进镁进入细胞 | 镁配 25-50mg B6（P5P 形式更佳） |
| 钙 + 维生素 D3 | D3 促进钙肠道吸收 | 钙 500mg 配 D3 1000IU |
| 辅酶 Q10 + Omega-3 | 脂溶性 CoQ10 在 Omega-3 中溶解度更好 | 随含脂肪餐同服 |
| NAC + 硫辛酸 + 硒 | 三者协同再生谷胱甘肽 | 整体抗氧化方案 |
| 锌 + 槲皮素 | 槲皮素是锌离子载体，增强锌进入细胞 | 锌 15-30mg + 槲皮素 500mg |

### 4.2 冲突组合（避免同时服用）

| 组合 | 冲突原因 | 处理 |
|------|---------|------|
| 钙 + 铁 | 竞争吸收通道 | 间隔 2 小时以上 |
| 钙 + 锌 | 高钙抑制锌吸收 | 间隔 2 小时以上 |
| 铜 + 锌（高剂量） | 锌诱导金属硫蛋白结合铜 | 锌 >30mg/天时补铜 1-2mg |
| 维生素 E + 铁 | 维 E 被铁氧化失活 | 间隔 2-4 小时 |
| 叶酸（合成） + 维 B12 检测 | 高剂量合成叶酸可掩盖 B12 缺乏症状 | 优先检测 B12 后再补叶酸 |

## 5. 剂量调整因子

### 5.1 年龄调整

| 年龄段 | 调整原则 |
|--------|---------|
| 18-30 岁 | 标准剂量；铁需求（女性月经期偏高） |
| 31-50 岁 | 标准剂量；关注 B12、D3 |
| 51-65 岁 | 维 D3 增加至 1000-2000IU；B12 可能需要舌下含服形式；钙 1000-1200mg |
| 65 岁以上 | 肾功能下降需降低镁、钾剂量；维 D3 建议 2000IU；蛋白质需求增加 |

### 5.2 体重调整

- 脂溶性维生素（A/D/E/K）：BMI > 30 时剂量增加 50-100%
- 维生素 D：肥胖个体（BMI ≥ 30）可能需要 2-3 倍常规剂量
- 镁：按体重 5-7mg/kg 计算

### 5.3 性别差异

| 补充剂 | 男性 | 女性 |
|--------|------|------|
| 铁 | 通常不需额外补充（除非检测证实缺乏） | 育龄期建议 18mg/天（月经导致铁丢失） |
| 叶酸 | 400μg DFE | 备孕/孕期 600-800μg DFE |
| 钙 | 1000mg/天 | 绝经后 1200mg/天 |
| 锌 | 11mg/天 | 8mg/天 |

### 5.4 肾功能调整（eGFR 分级）

| eGFR (mL/min/1.73m²) | 调整 |
|----------------------|------|
| ≥ 90（正常） | 标准剂量 |
| 60-89（轻度下降） | 注意钾、镁摄入量，不超过 RDA |
| 30-59（中度下降） | 避免含钾补充剂；镁剂量减半；避免含铝制剂 |
| < 30（重度下降） | 仅在肾内科医生指导下使用补充剂 |

## 6. 补充剂质量选择标准

### 6.1 第三方检测认证

| 认证机构 | 检测范围 | 可信度 |
|---------|---------|--------|
| USP（美国药典） | 纯度、溶解性、标签准确性、污染物 | 最高 |
| NSF International | 运动禁用物质筛查、GMP | 高（运动员首选） |
| ConsumerLab | 含量准确性、污染物、崩解试验 | 高（独立检测） |
| IFOS（鱼油） | 氧化值、重金属、PCBs | 鱼油专项金标准 |
| Informed Sport | 兴奋剂筛查 | 高（竞技运动员） |
| 蓝帽子标志（中国） | CFDA 保健食品注册 | 合规性保障 |

### 6.2 生物利用度优选形式

| 补充剂 | 推荐形式 | 避免形式 | 说明 |
|--------|---------|---------|------|
| 镁 | 甘氨酸镁、苏糖酸镁、牛磺酸镁 | 氧化镁（吸收率 <4%） | 甘氨酸镁综合最佳；苏糖酸镁穿透血脑屏障 |
| 铁 | 双甘氨酸亚铁、铁蛋白 | 硫酸亚铁（胃肠道反应大） | 螯合铁胃肠道耐受性好 |
| 叶酸 | 5-MTHF（甲基叶酸） | 合成叶酸（folic acid） | MTHFR 变异者无法转化合成叶酸 |
| B12 | 甲基钴胺素、腺苷钴胺素 | 氰钴胺素 | 甲基型直接参与甲基化 |
| 锌 | 吡啶甲酸锌、双甘氨酸锌 | 氧化锌（吸收率低） | 螯合形式吸收率高 2-3 倍 |
| 辅酶 Q10 | 泛醇（Ubiquinol） | 泛醌（Ubiquinone） | 泛醇是活性还原形式，40 岁后转化能力下降 |
| 姜黄素 | 纳米胶束、磷脂复合、胡椒碱配方 | 普通姜黄粉 | 普通姜黄素生物利用度极低（<1%） |
| Omega-3 | rTG 型（再酯化甘油三酯） | EE 型（乙酯型） | rTG 型吸收率比 EE 型高约 70% |

## 7. 监测协议

### 7.1 补充剂效果监测指标

| 补充剂 | 监测指标 | 目标范围 | 复查周期 |
|--------|---------|---------|---------|
| 维生素 D3 | 25(OH)D | 30-60 ng/mL（75-150 nmol/L） | 补充 3 个月后复查 |
| 铁剂 | 血清铁蛋白、TIBC、转铁蛋白饱和度 | 铁蛋白 30-150 ng/mL | 补充 2-3 个月后复查 |
| B12 | 血清 B12、同型半胱氨酸、MMA | B12 > 400 pg/mL；Hcy < 10 μmol/L | 补充 3 个月后复查 |
| 叶酸 | 红细胞叶酸、同型半胱氨酸 | RBC 叶酸 > 400 ng/mL | 补充 3 个月后复查 |
| 锌 | 血清锌 | 70-120 μg/dL | 补充 2 个月后复查 |
| Omega-3 | Omega-3 指数（红细胞 EPA+DHA%） | ≥ 8%（理想）；< 4% 高风险 | 补充 4-6 个月后复查 |
| 镁 | 红细胞内镁（优于血清镁） | 4.2-6.8 mg/dL（红细胞内） | 补充 3 个月后复查 |
| 辅酶 Q10 | 血浆 CoQ10 | > 2.0 μg/mL | 补充 3 个月后复查 |
| 甲基化支持 | 同型半胱氨酸（Hcy） | < 10 μmol/L（理想 < 7） | 干预 3 个月后复查 |

### 7.2 安全性监测

| 风险项 | 监测指标 | 警戒值 | 适用补充剂 |
|--------|---------|--------|-----------|
| 维生素 D 中毒 | 血钙、25(OH)D | 25(OH)D > 100 ng/mL 或血钙升高 | 高剂量维 D（>4000IU/天） |
| 铁过载 | 铁蛋白、转铁蛋白饱和度 | 铁蛋白 > 300 ng/mL（男）/ > 200（女） | 铁剂 |
| 维生素 A 中毒 | 视黄醇 | > 3.0 μmol/L | 预成型维 A（视黄醇） |
| 肾功能 | eGFR、肌酐、BUN | eGFR 下降趋势 | 高蛋白/肌酸/长期多种补充剂 |
| 肝功能 | ALT、AST、ALP | ALT > 2 倍正常上限 | 草药提取物、高剂量烟酸 |
| 凝血功能 | PT/INR | INR 异常波动 | 鱼油、维 E、维 K（使用抗凝药时） |
