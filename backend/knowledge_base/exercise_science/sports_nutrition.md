# 运动营养指南

> 营养是运动表现和恢复的基础

## 一、运动营养基础

### 1.1 三大宏量营养素

#### 碳水化合物 - 主要能量来源
```
功能：
- 运动时的主要燃料
- 高强度运动的唯一能量来源
- 储存为肌糖原和肝糖原

运动员需求：
- 低强度训练：3-5 g/kg/天
- 中等强度训练：5-7 g/kg/天
- 高强度训练：6-10 g/kg/天
- 极高强度：8-12 g/kg/天

优质来源：
- 全谷物（燕麦、糙米）
- 红薯、土豆
- 水果
- 蔬菜
```

#### 蛋白质 - 肌肉修复与增长
```
功能：
- 肌肉修复和增长
- 酶和激素合成
- 免疫功能

运动员需求：
- 普通成人：0.8 g/kg/天
- 耐力运动：1.2-1.4 g/kg/天
- 力量训练：1.6-2.2 g/kg/天
- 减脂期：2.0-2.4 g/kg/天

优质来源：
- 瘦肉（鸡胸、牛肉）
- 鱼类（三文鱼、鳕鱼）
- 蛋类
- 乳制品
- 豆类
```

#### 脂肪 - 长时间运动能量
```
功能：
- 长时间低强度运动燃料
- 吸收脂溶性维生素
- 激素合成

运动员需求：
- 占总热量 20-35%
- 避免低于20%

优质来源：
- 橄榄油
- 坚果
- 牛油果
- 深海鱼
```

### 1.2 运动前营养

**时间安排：**
| 时间 | 进食策略 |
|------|---------|
| 3-4小时前 | 正常大餐（碳水+蛋白质+脂肪） |
| 2-3小时前 | 中等餐（碳水为主，低脂） |
| 1-2小时前 | 轻食（易消化碳水） |
| 30分钟内 | 小零食或不吃 |

**推荐食物：**
- 燕麦 + 香蕉
- 全麦面包 + 花生酱
- 米饭 + 鸡肉
- 能量棒

**避免：**
- 高纤维食物（可能引起胃不适）
- 高脂肪食物（消化慢）
- 尝试新食物（比赛前）

### 1.3 运动中营养

**短时间运动（<60分钟）：**
- 水分即可
- 一般不需要额外能量补充

**长时间运动（>60分钟）：**
- 每小时30-60g碳水化合物
- 每15-20分钟150-200ml水

**碳水来源：**
- 运动饮料
- 能量胶
- 香蕉
- 能量棒

### 1.4 运动后营养

**目标：**
1. 补充糖原
2. 修复肌肉
3. 补充水分

**黄金窗口：训练后30-60分钟**

**推荐比例：**
- 碳水：蛋白质 = 3:1 或 4:1

**简单选择：**
- 巧克力牛奶（碳水+蛋白质）
- 蛋白粉 + 香蕉
- 酸奶 + 水果 + 蜂蜜
- 鸡胸肉三明治

## 二、水分与电解质

### 2.1 水分需求

**基础需求：**
- 每公斤体重 30-40ml
- 60kg体重：1.8-2.4L/天

**运动额外需求：**
- 运动前2小时：400-600ml
- 运动中：每15-20分钟150-200ml
- 运动后：流失体重的150%

### 2.2 脱水影响

| 脱水程度 | 影响 |
|---------|------|
| 1-2% | 开始影响表现 |
| 3-4% | 明显表现下降 |
| 5%+ | 可能危及健康 |

**脱水信号：**
- 口渴
- 尿液颜色深
- 头痛
- 疲劳

### 2.3 电解质

**主要电解质：**
- 钠：维持体液平衡
- 钾：肌肉收缩
- 镁：能量代谢
- 钙：骨骼健康

**补充时机：**
- 运动超过60分钟
- 大量出汗
- 高温环境运动

**来源：**
- 运动饮料
- 电解质片
- 盐（适量）
- 香蕉（钾）

## 三、不同训练目标的营养策略

### 3.1 增肌期

**热量：** 热量盈余 300-500 kcal/天

**宏量分配：**
- 蛋白质：2.0-2.2 g/kg
- 碳水：4-6 g/kg
- 脂肪：0.8-1.2 g/kg

**进食频率：** 4-6餐/天

**重点：**
- 训练前后营养最重要
- 每餐含20-40g蛋白质
- 睡前可补充缓释蛋白

### 3.2 减脂期

**热量：** 热量赤字 300-500 kcal/天

**宏量分配：**
- 蛋白质：2.2-2.4 g/kg（高蛋白防止肌肉流失）
- 碳水：2-3 g/kg（根据活动量调整）
- 脂肪：0.6-1.0 g/kg

**策略：**
- 提高蛋白质比例
- 保持力量训练
- 不要减太快（每周0.5-1%体重）

### 3.3 耐力训练

**热量：** 匹配训练消耗

**宏量分配：**
- 蛋白质：1.2-1.6 g/kg
- 碳水：5-10 g/kg（根据训练量）
- 脂肪：0.8-1.2 g/kg

**特别注意：**
- 长距离训练前充分补充糖原
- 训练中补充能量（>60分钟）
- 训练后快速恢复糖原

## 四、常见运动补剂

### 4.1 有科学证据支持的补剂

#### 蛋白粉
```
作用：方便补充蛋白质
推荐类型：乳清蛋白（吸收快）
用量：20-40g/次
时机：训练后、早餐、加餐
```

#### 肌酸
```
作用：提高力量和爆发力
推荐类型：一水肌酸
用量：每天3-5g
注意：需要loading期或直接维持
```

#### 咖啡因
```
作用：提高运动表现、延缓疲劳
用量：3-6 mg/kg，运动前30-60分钟
注意：下午后避免（影响睡眠）
```

#### β-丙氨酸
```
作用：提高耐力、缓冲乳酸
用量：每天3.2-6.4g（分次服用）
注意：可能引起皮肤刺痛感
```

### 4.2 可能有效的补剂

- **BCAA**：已摄入足够蛋白质时意义不大
- **谷氨酰胺**：日常饮食已足够
- **HMB**：对新手可能有效

### 4.3 不推荐的补剂

- 大多数"燃脂"补剂
- 睾酮促进剂
- 过度宣传的神奇产品

## 五、实用建议

### 5.1 一天饮食示例（增肌/力量训练）

**体重70kg，训练日**

```
早餐（7:00）
- 燕麦 60g + 牛奶 250ml
- 鸡蛋 2个
- 香蕉 1根
蛋白质：25g，碳水：60g

加餐（10:00）
- 坚果 30g
- 酸奶 150g
蛋白质：12g，碳水：15g

午餐（12:30）
- 糙米 150g
- 鸡胸肉 150g
- 蔬菜适量
蛋白质：45g，碳水：70g

训练前（16:00）
- 香蕉 1根
- 蛋白棒 1根
蛋白质：15g，碳水：40g

训练（17:00-18:30）

训练后（18:30）
- 蛋白粉 30g + 香蕉 1根
蛋白质：25g，碳水：30g

晚餐（19:30）
- 红薯 150g
- 三文鱼 150g
- 蔬菜沙拉
蛋白质：35g，碳水：50g

睡前（22:00）
- 酪蛋白或牛奶 250ml
蛋白质：20g

总计：约 2500kcal，蛋白质177g，碳水265g
```

### 5.2 备赛/比赛营养策略

**赛前一周：**
- 增加碳水摄入（糖原超量储存）
- 减少纤维摄入
- 充足水分

**比赛当天：**
- 比赛前3-4小时：易消化的大餐
- 比赛前30分钟：少量水、能量胶
- 比赛中：按计划补充

**赛后：**
- 尽快补充碳水和蛋白质
- 充足水分和电解质
