# 力量训练基础指南

> 力量训练是健康的重要组成部分，能够增强肌肉、骨骼和代谢功能

## 一、为什么要进行力量训练

### 1.1 力量训练的好处

1. **增加肌肉量**
   - 提高基础代谢率
   - 改善身体成分（降低体脂率）
   - 塑造体型

2. **强化骨骼**
   - 预防骨质疏松
   - 降低骨折风险
   - 对中老年人尤为重要

3. **改善功能**
   - 提高日常活动能力
   - 增强运动表现
   - 预防运动伤病

4. **代谢健康**
   - 改善胰岛素敏感性
   - 调节血糖
   - 改善血脂

5. **心理健康**
   - 增强自信
   - 缓解抑郁和焦虑
   - 改善睡眠

### 1.2 常见误区

**误区一：力量训练会让人变得很壮**
- 真相：增肌需要大量训练和营养支持
- 普通训练只会让身体更紧实

**误区二：女性不应该做力量训练**
- 真相：女性更需要力量训练
- 女性激素水平决定不会轻易"变壮"

**误区三：年纪大了不适合力量训练**
- 真相：中老年人更需要力量训练
- 可以有效预防肌肉流失（肌少症）

## 二、基础动作模式

### 2.1 六大基本动作模式

1. **推（Push）**
   - 俯卧撑、卧推、肩推
   - 训练：胸肌、三角肌、三头肌

2. **拉（Pull）**
   - 引体向上、划船、硬拉
   - 训练：背阔肌、二头肌

3. **蹲（Squat）**
   - 深蹲、箭步蹲、分腿蹲
   - 训练：股四头肌、臀肌

4. **髋铰链（Hip Hinge）**
   - 硬拉、罗马尼亚硬拉、壶铃摆动
   - 训练：腘绳肌、臀肌、下背

5. **核心稳定（Core）**
   - 平板支撑、死虫式、鸟狗式
   - 训练：腹肌、腰背深层肌群

6. **负重行走（Carry）**
   - 农夫走、行李箱走
   - 训练：核心稳定、握力

### 2.2 徒手训练动作

#### 俯卧撑 (Push-up)
```
目标肌群：胸大肌、三角肌前束、三头肌

要点：
1. 双手略宽于肩，手指朝前
2. 身体成一条直线，核心收紧
3. 下降至胸部接近地面
4. 推起时手臂不要完全锁死

变式：
- 简化：跪姿俯卧撑、墙壁俯卧撑
- 进阶：钻石俯卧撑、单手俯卧撑
```

#### 深蹲 (Squat)
```
目标肌群：股四头肌、臀大肌、腘绳肌

要点：
1. 双脚与肩同宽或略宽
2. 脚尖微微外八
3. 蹲下时膝盖沿脚尖方向
4. 蹲至大腿与地面平行或更低
5. 重心在脚中后部

变式：
- 简化：椅子蹲（屁股碰椅子）
- 进阶：单腿蹲、跳跃深蹲
```

#### 平板支撑 (Plank)
```
目标肌群：腹横肌、腹直肌、下背肌群

要点：
1. 前臂支撑，肘部在肩膀正下方
2. 身体成一条直线
3. 腹部收紧，臀部不要塌或翘
4. 保持正常呼吸

时间：
- 初学：15-30秒 × 3组
- 进阶：60-90秒 × 3组
```

#### 引体向上 (Pull-up)
```
目标肌群：背阔肌、二头肌、核心

要点：
1. 正握杠，略宽于肩
2. 从死点开始，肩胛骨下沉
3. 拉至下巴过杠
4. 控制下降

变式：
- 简化：弹力带辅助、反向划船
- 进阶：负重引体、单手引体
```

#### 臀桥 (Glute Bridge)
```
目标肌群：臀大肌、腘绳肌

要点：
1. 仰卧，双脚踩地
2. 收紧臀部，抬起骨盆
3. 身体从肩到膝成直线
4. 顶点停顿，感受臀部收缩

变式：
- 进阶：单腿臀桥、负重臀桥
```

## 三、训练计划设计

### 3.1 训练变量

1. **频率（Frequency）**
   - 每周训练次数
   - 推荐：2-4次/周

2. **强度（Intensity）**
   - 重量相对于最大力量的百分比
   - 或者主观疲劳度（RPE）

3. **容量（Volume）**
   - 组数 × 次数 × 重量
   - 推荐：每肌群10-20组/周

4. **休息时间（Rest）**
   - 力量训练：2-3分钟
   - 肌肉增长：1-2分钟
   - 耐力训练：30-60秒

### 3.2 新手计划（每周2-3次）

**全身训练计划 A：**
```
1. 深蹲 3×10
2. 俯卧撑 3×10（或跪姿）
3. 臀桥 3×12
4. 反向划船 3×10
5. 平板支撑 3×30秒
```

**全身训练计划 B：**
```
1. 箭步蹲 3×10（每腿）
2. 上斜俯卧撑 3×10
3. 罗马尼亚硬拉（徒手）3×12
4. 超人式 3×10
5. 死虫式 3×10（每侧）
```

**周安排：**
```
周一：计划A
周三：计划B
周五：计划A
下周：B-A-B
```

### 3.3 进阶计划（分化训练）

**上下肢分化（4天/周）：**

**Day 1 - 上肢推：**
```
1. 俯卧撑/卧推 4×8-12
2. 肩推 3×10
3. 三头臂屈伸 3×12
4. 侧平举 3×12
```

**Day 2 - 下肢：**
```
1. 深蹲 4×8-12
2. 罗马尼亚硬拉 3×10
3. 箭步蹲 3×10
4. 小腿提踵 3×15
```

**Day 3 - 休息**

**Day 4 - 上肢拉：**
```
1. 引体向上/划船 4×8-12
2. 坐姿划船 3×10
3. 面拉 3×15
4. 二头弯举 3×12
```

**Day 5 - 下肢+核心：**
```
1. 硬拉 4×6-8
2. 保加利亚分腿蹲 3×10
3. 臀推 3×12
4. 平板支撑 3×45秒
5. 卷腹 3×15
```

### 3.4 渐进超负荷

**什么是渐进超负荷：**
逐渐增加训练难度，迫使身体适应和进步

**方法：**
1. 增加重量（最直接）
2. 增加次数
3. 增加组数
4. 减少休息时间
5. 增加动作范围
6. 改变节奏（慢速离心）

**示例：**
```
第1周：深蹲 40kg × 10 × 3
第2周：深蹲 40kg × 12 × 3
第3周：深蹲 42.5kg × 10 × 3
第4周：深蹲 42.5kg × 10 × 4
```

## 四、常见问题

### Q1：没有器械怎么练？

**徒手训练足够有效：**
- 俯卧撑、引体向上、深蹲、臀桥
- 使用家具：椅子、桌子、墙壁
- 购买基础器械：哑铃、弹力带、单杠

### Q2：力量训练和有氧哪个先做？

**取决于目标：**
- 以力量为主：先力量后有氧
- 以减脂为主：先力量后有氧（同样）
- 以耐力为主：先有氧或分开练

### Q3：肌肉酸痛还能练吗？

**区分情况：**
- 轻度酸痛（DOMS）：可以练，但降低强度
- 剧烈疼痛：休息，可能是伤病
- 持续超过72小时：考虑过度训练

### Q4：多久能看到效果？

**大致时间线：**
- 2周：开始感觉力量提升
- 4-6周：身体开始有变化
- 8-12周：明显的外观改变
- 坚持就是胜利！

## 五、安全注意事项

1. **充分热身**
   - 5-10分钟有氧
   - 动态拉伸
   - 轻重量预激活

2. **正确姿势优先于重量**
   - 宁轻勿重
   - 必要时请教练

3. **循序渐进**
   - 不要急于增加重量
   - 每周增幅不超过5-10%

4. **倾听身体**
   - 疼痛时停止
   - 充分休息恢复
