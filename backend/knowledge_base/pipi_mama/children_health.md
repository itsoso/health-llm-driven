# 儿童健康管理 - 皮皮妈妈

## 一、儿童生长发育

### 生长指标监测

1. **身高**
   - 0-1岁：增长约25cm
   - 1-2岁：增长约10-12cm
   - 2岁后：每年增长5-7cm
   - 青春期：猛长期

2. **体重**
   - 出生：约3kg
   - 3-4个月：体重翻倍
   - 1岁：出生体重3倍
   - 2岁后：每年增长约2kg

3. **头围**
   - 反映脑发育
   - 出生：约34cm
   - 1岁：约46cm
   - 3岁接近成人

### 发育里程碑

**运动发育**
- 2-3个月：抬头
- 6个月：独坐
- 8-10个月：爬行
- 12-15个月：独走
- 2岁：跑跳

**语言发育**
- 2-3个月：咿呀发声
- 7-8个月：无意义叫爸妈
- 1岁：有意义叫爸妈
- 2岁：简单句子
- 3岁：完整表达

**注意**：发育有个体差异，不要过度焦虑，但明显落后要就医。

## 二、儿童常见健康问题

### 腹泻

**常见原因**
- 病毒感染（轮状病毒等）
- 细菌感染
- 食物不耐受
- 抗生素相关

**家庭处理**
- 预防脱水最重要
- 口服补液盐（ORS）
- 继续进食（不要禁食）
- 母乳喂养不要停
- 蒙脱石散可以用

**就医信号**
- 严重脱水
- 血便
- 高热不退
- 精神差
- 腹泻超过2周

### 便秘

**识别**
- 排便困难
- 大便干硬
- 排便疼痛
- 次数明显减少

**家庭处理**
- 增加膳食纤维
- 多喝水
- 培养规律排便习惯
- 增加活动
- 必要时使用开塞露

**预防**
- 饮食均衡
- 充足饮水
- 规律运动
- 不要忍便

### 咳嗽

**常见原因**
- 上呼吸道感染
- 支气管炎
- 肺炎
- 哮喘
- 鼻后滴漏

**何时担心**
- 呼吸急促
- 呼吸费力
- 嘴唇发紫
- 咳嗽超过2周
- 伴有高热

**护理要点**
- 多喝水
- 保持空气湿润
- 不要盲目止咳
- 找出病因更重要

### 手足口病

**症状**
- 发热
- 口腔疱疹、溃疡
- 手、足、臀部皮疹
- 疱疹水泡

**家庭护理**
- 隔离（发病后7-10天）
- 清淡饮食
- 口腔护理
- 皮疹护理
- 多喝水

**严重信号（需急诊）**
- 持续高热
- 精神差、嗜睡
- 频繁呕吐
- 肢体抖动
- 呼吸心率异常

## 三、儿童营养

### 各年龄段营养要点

**0-6个月**
- 纯母乳喂养最佳
- 配方奶喂养要正确冲调
- 补充维生素D（400IU/天）

**6-12个月**
- 开始添加辅食
- 富含铁的食物优先
- 逐步尝试多种食物
- 继续母乳/配方奶

**1-3岁**
- 过渡到家庭饮食
- 奶量500ml左右
- 三餐两点
- 培养自主进食

**学龄前/学龄期**
- 均衡饮食
- 控制零食
- 足够的钙和蛋白质
- 避免肥胖

### 儿童常见营养问题

**挑食偏食**
- 不要强迫进食
- 多次尝试新食物
- 家长以身作则
- 让孩子参与烹饪
- 食物多样化呈现

**缺铁**
- 6个月后高发
- 多吃红肉、肝脏
- 配合维生素C促进吸收
- 严重者需补铁剂

**缺钙**
- 保证奶量
- 深绿色蔬菜
- 豆制品
- 户外活动（维生素D合成）

## 四、儿童睡眠

### 各年龄段睡眠需求

- 0-3个月：14-17小时
- 4-11个月：12-15小时
- 1-2岁：11-14小时
- 3-5岁：10-13小时
- 6-13岁：9-11小时

### 培养良好睡眠习惯

1. **建立睡前程序**
   - 洗澡
   - 换睡衣
   - 刷牙
   - 讲故事
   - 道晚安

2. **固定睡眠时间**
   - 每天同一时间上床
   - 周末也保持规律

3. **创造睡眠环境**
   - 安静
   - 黑暗
   - 舒适的温度
   - 安全感

4. **避免睡前刺激**
   - 不看电子屏幕
   - 不做剧烈运动
   - 不吃太多东西

### 常见睡眠问题

**夜醒**
- 婴儿夜醒是正常的
- 逐渐培养自主入睡
- 排除饥饿、不适等原因

**入睡困难**
- 检查睡眠环境
- 固定睡前程序
- 避免过度疲劳入睡

**梦游/夜惊**
- 学龄前儿童较常见
- 通常不需要特殊处理
- 保证安全
- 随年龄会改善

## 五、儿童安全

### 意外伤害预防

**跌落**
- 婴儿不要单独放高处
- 楼梯装护栏
- 窗户装限位器
- 阳台防护

**烫伤**
- 热水器温度设定<50°C
- 热饮放高处
- 厨房限制进入
- 洗澡先放冷水

**误食/中毒**
- 药品、清洁剂锁好
- 不要用饮料瓶装危险液体
- 小物件收好
- 植物可能有毒

**溺水**
- 儿童戏水需全程看护
- 浴缸不留水
- 学习游泳
- 不在无人水域游泳

### 常见意外处理

**小伤口**
- 清水冲洗
- 消毒
- 创可贴覆盖
- 保持干燥

**烫伤**
- 立即冷水冲15-20分钟
- 不要涂牙膏、酱油等
- 不要挑破水泡
- 严重者就医

**流鼻血**
- 头略前倾
- 捏住鼻翼10分钟
- 不要仰头
- 不要塞纸巾

**撞头**
- 观察意识状态
- 冷敷
- 注意呕吐、嗜睡等
- 严重撞击要就医

## 六、儿童心理健康

### 情绪发展

- 婴儿期：基本情绪（快乐、愤怒、恐惧）
- 幼儿期：自我意识发展
- 学龄期：社交情绪发展

### 培养心理健康

1. **无条件的爱**
   - 让孩子感到被爱
   - 不因表现好坏改变

2. **安全的依恋**
   - 及时回应需求
   - 稳定的照顾者

3. **鼓励探索**
   - 允许犯错
   - 培养独立性
   - 支持好奇心

4. **情绪教育**
   - 识别情绪
   - 表达情绪
   - 管理情绪

### 何时寻求帮助

- 行为明显异常
- 社交困难
- 学习困难
- 情绪问题持续
- 出现退行行为
