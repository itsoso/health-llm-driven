# 过敏管理知识 - 皮皮妈妈

## 一、认识过敏

### 什么是过敏

过敏是免疫系统对无害物质的过度反应。当免疫系统把花粉、尘螨、某些食物等误认为"敌人"，就会发起攻击，产生过敏症状。

### 过敏的机制

1. 首次接触过敏原 → 免疫系统"记住"
2. 产生特异性IgE抗体
3. 再次接触 → IgE与肥大细胞结合
4. 释放组胺等物质 → 引起症状

### 常见过敏原

1. **吸入性过敏原**
   - 尘螨
   - 花粉
   - 霉菌
   - 动物皮屑
   - 蟑螂

2. **食物过敏原**
   - 牛奶
   - 鸡蛋
   - 花生/坚果
   - 海鲜
   - 小麦
   - 大豆

3. **接触性过敏原**
   - 金属（镍）
   - 乳胶
   - 化妆品
   - 某些植物

4. **药物过敏原**
   - 青霉素类
   - 磺胺类
   - 阿司匹林

## 二、常见过敏性疾病

### 过敏性鼻炎

**症状**
- 打喷嚏（连续多个）
- 流清水样鼻涕
- 鼻塞
- 鼻痒
- 眼痒、流泪

**分类**
- 季节性：花粉过敏为主
- 常年性：尘螨过敏为主

**管理要点**
- 避免接触过敏原
- 鼻腔冲洗（每日1-2次）
- 抗组胺药（西替利嗪、氯雷他定）
- 鼻用激素喷剂（长期控制）
- 严重者考虑脱敏治疗

### 哮喘

**症状**
- 反复发作的喘息
- 气促
- 胸闷
- 咳嗽（尤其夜间和清晨）

**诱因**
- 过敏原
- 呼吸道感染
- 运动
- 冷空气
- 烟雾

**管理要点**
- 规范使用控制药物（吸入激素）
- 随身携带急救药物
- 学会正确使用吸入装置
- 监测峰流速
- 避免诱因

### 湿疹/特应性皮炎

**症状**
- 皮肤干燥
- 红斑
- 瘙痒
- 渗出
- 结痂

**好发部位**
- 婴儿：面部、头皮
- 儿童：肘窝、膝窝
- 成人：手部、颈部

**管理要点**
- 保湿！保湿！保湿！（一天多次）
- 避免刺激（热水、香皂、毛织品）
- 按医嘱使用外用激素
- 控制瘙痒（抗组胺药）
- 寻找并避免诱因

### 食物过敏

**症状范围**
- 轻度：皮疹、荨麻疹、嘴唇肿胀
- 中度：呕吐、腹泻、腹痛
- 重度：呼吸困难、血压下降（过敏性休克）

**注意事项**
- 严格回避过敏食物
- 学会阅读食品标签
- 携带急救药物（严重过敏者）
- 定期复查，部分可能耐受

## 三、过敏的预防与管理

### 环境控制

**针对尘螨**
- 床上用品每周热水（55°C以上）洗涤
- 使用防螨床罩
- 保持室内干燥（湿度<50%）
- 减少地毯、毛绒玩具
- 定期清洁

**针对花粉**
- 花粉季减少外出
- 外出戴口罩
- 回家后换衣服、洗澡
- 关闭门窗
- 使用空气净化器

**针对霉菌**
- 保持通风
- 控制湿度
- 清除发霉的物品
- 使用除湿机

**针对宠物**
- 最好不养（如果严重过敏）
- 宠物不进卧室
- 定期给宠物洗澡
- 使用空气净化器

### 药物治疗

**抗组胺药**
- 第一代：扑尔敏（嗜睡）
- 第二代：氯雷他定、西替利嗪（首选）
- 儿童剂型：糖浆、滴剂

**鼻用激素**
- 过敏性鼻炎的一线用药
- 需要坚持使用
- 局部作用，全身副作用小
- 常用：布地奈德、糠酸莫米松

**外用药物**
- 保湿剂：基础治疗
- 外用激素：控制炎症
- 钙调磷酸酶抑制剂：敏感部位

### 脱敏治疗

**原理**
- 逐渐增加过敏原剂量
- 让免疫系统产生耐受

**适用情况**
- 明确的过敏原
- 药物控制效果差
- 愿意长期坚持

**方式**
- 皮下注射
- 舌下含服

**疗程**
- 通常3-5年
- 需要坚持

## 四、过敏的误区

### 误区1：过敏可以根治

事实：
- 过敏是体质问题，不能"根治"
- 可以很好地控制
- 部分儿童可能随年龄"长出去"
- 脱敏治疗可以达到长期缓解

### 误区2：激素很可怕

事实：
- 外用/吸入激素局部作用为主
- 规范使用非常安全
- 不用反而更危险
- 与口服激素不同

### 误区3：检测阴性就不是过敏

事实：
- 检测有假阴性的可能
- 有些过敏原检测不到
- 临床症状更重要
- 可能需要多种检测方法

### 误区4：过敏就要忌口很多东西

事实：
- 只需回避确认的过敏食物
- 不要盲目忌口
- 可能导致营养不良
- 食物过敏原需要专业确认

## 五、紧急情况处理

### 严重过敏反应（过敏性休克）

**识别**
- 全身荨麻疹
- 呼吸困难
- 喉头水肿
- 血压下降
- 意识模糊

**处理**
1. 立即拨打120
2. 远离过敏原
3. 让患者平躺、抬高下肢
4. 如有肾上腺素自注射器，立即使用
5. 如果呼吸/心跳停止，进行心肺复苏

**高危人群**
- 有过敏性休克史的人
- 严重食物过敏者
- 蜂毒过敏者

这些人应该随身携带肾上腺素自注射器，并学会使用。

## 六、儿童过敏的特点

### 过敏进程

许多儿童的过敏会经历一个"进程"：
1. 婴儿期：湿疹、食物过敏
2. 幼儿期：哮喘
3. 学龄期：过敏性鼻炎

这叫"过敏进程"（Atopic March）

### 预防策略

- 母乳喂养
- 适时添加辅食
- 早期接触多样化食物（除非已确认过敏）
- 避免二手烟
- 减少室内过敏原暴露

### 何时就医

- 症状影响生活质量
- 药物控制效果差
- 需要明确过敏原
- 考虑脱敏治疗
- 有严重过敏反应史
