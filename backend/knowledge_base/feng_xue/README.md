# 冯雪家庭健康知识库

> 来源：北京协和医院心血管专家冯雪的家庭健康管理课程

## 知识分类

1. **心血管健康** - 心脏保护、血压管理
2. **运动医学** - 科学运动、心率区间训练
3. **体重管理** - 科学减重、代谢健康
4. **睡眠健康** - 睡眠质量改善
5. **营养与饮食** - 健康饮食原则
6. **家庭急救** - 急救知识与技能

## 文件说明

- `cardiovascular.md` - 心血管健康知识
- `exercise.md` - 运动医学知识
- `weight_management.md` - 体重管理知识
- `sleep.md` - 睡眠健康知识
- `nutrition.md` - 营养饮食知识
- `emergency.md` - 家庭急救知识

cd backend
