# 运动医学知识 - 冯雪

## 一、运动的科学原理

### 运动对身体的益处

1. **心血管系统**
   - 增强心肌收缩力
   - 降低静息心率
   - 改善血管弹性
   - 降低血压

2. **代谢系统**
   - 提高基础代谢率
   - 改善胰岛素敏感性
   - 促进脂肪燃烧
   - 调节血脂水平

3. **骨骼肌肉系统**
   - 增强肌肉力量
   - 提高骨密度
   - 保护关节
   - 改善平衡能力

4. **神经系统**
   - 释放内啡肽，改善情绪
   - 提高认知功能
   - 改善睡眠质量
   - 缓解压力和焦虑

## 二、有氧运动指南

### 什么是有氧运动

有氧运动是指持续时间较长、强度中等、以有氧代谢为主的运动。

### 常见有氧运动

1. **快走** - 最安全、最易行的有氧运动
   - 配速：6-7km/h
   - 心率：最大心率的60-70%
   - 适合：所有人群，特别是初学者

2. **跑步** - 高效的心肺训练
   - 建议从跑走结合开始
   - 逐渐增加跑步比例
   - 每周增加里程不超过10%

3. **游泳** - 全身性运动
   - 对关节友好
   - 适合超重人群
   - 注意水温和安全

4. **骑自行车** - 膝关节友好
   - 室内动感单车可控性强
   - 户外骑行注意安全

### 有氧运动的FITT原则

- **F (Frequency)**: 每周3-5次
- **I (Intensity)**: 中等强度，心率60-80%最大心率
- **T (Time)**: 每次30-60分钟
- **T (Type)**: 选择喜欢的运动类型

## 三、力量训练指南

### 力量训练的重要性

- 增加肌肉量，提高基础代谢
- 预防肌少症
- 保护关节
- 改善体态

### 基础力量动作

1. **深蹲** - 下肢力量之王
   - 要点：膝盖与脚尖同向，背部挺直
   - 变化：徒手→杠铃→前蹲

2. **俯卧撑** - 上肢推力训练
   - 要点：核心收紧，身体成一条直线
   - 变化：跪姿→标准→窄距→击掌

3. **平板支撑** - 核心稳定训练
   - 要点：身体成一条直线，避免塌腰
   - 目标：从30秒逐渐增加到2分钟

4. **引体向上** - 上肢拉力训练
   - 可以从弹力带辅助开始
   - 逐渐减少辅助

### 力量训练频率

- 初学者：每周2次全身训练
- 进阶者：每周3-4次，分部位训练
- 同一肌群间隔48小时以上

## 四、运动与恢复

### 恢复的重要性

运动的效果=训练×恢复。没有充分恢复，训练效果会大打折扣。

### 恢复策略

1. **睡眠**
   - 运动后需要更多睡眠
   - 深睡眠期间生长激素分泌增加
   - 建议运动日睡眠不少于7.5小时

2. **营养**
   - 运动后30分钟内补充蛋白质和碳水
   - 蛋白质：帮助肌肉修复
   - 碳水：补充糖原储备

3. **主动恢复**
   - 轻度活动促进血液循环
   - 泡沫轴放松肌筋膜
   - 拉伸缓解肌肉紧张

4. **被动恢复**
   - 冷热交替浴
   - 按摩
   - 压缩衣

### 过度训练的信号

- 持续疲劳，恢复变慢
- 运动表现下降
- 静息心率升高
- 睡眠质量下降
- 容易生病
- 情绪低落，缺乏运动动力

## 五、特殊人群运动建议

### 心血管疾病患者

- 必须在医生指导下运动
- 从低强度开始，循序渐进
- 避免竞技性运动
- 随身携带急救药物

### 糖尿病患者

- 运动有助于控制血糖
- 避免空腹运动
- 运动前后监测血糖
- 随身携带糖果

### 老年人

- 重视力量训练，预防肌少症
- 加入平衡训练，预防跌倒
- 注意关节保护
- 避免憋气用力

### 孕产妇

- 孕早期可继续孕前运动习惯
- 避免仰卧位运动
- 不适合高温运动
- 产后恢复需循序渐进
