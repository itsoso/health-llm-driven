# Web 界面课程上传指南

> 通过 Web 界面上传张展晖运动科学课程到知识库

## 🌐 访问地址

https://health.westwetlandtech.com/knowledge

或本地开发环境：http://localhost:3000/knowledge

---

## 📋 使用步骤

### 1. 登录管理员账号

确保使用**管理员账号**登录，普通用户无法访问知识库管理功能。

### 2. 进入知识库管理页面

点击导航栏的"知识库"或直接访问 `/knowledge` 路径

### 3. 切换到"上传内容"标签

点击顶部的 **📤 上传内容** 标签

### 4. 使用"上传专业课程"功能

页面顶部会看到一个紫色渐变的"🎓 上传专业课程"区域，这是专为张展晖课程优化的增强版上传器。

---

## 📝 填写表单

### 必填字段

#### 1. 课程标题
```
例如：心率区间训练法
```

#### 2. 来源标识
```
例如：zhang_zhanhui_01
建议格式：作者拼音_序号
```

#### 3. 课程内容
粘贴完整的 Markdown 格式课程内容

### 选填字段

#### 4. 作者
```
默认：张展晖
可修改为其他作者
```

#### 5. 难度级别
- 初级 (Beginner) - 适合零基础
- 中级 (Intermediate) - 适合有一定基础 ⭐ 默认
- 高级 (Advanced) - 适合进阶人群

#### 6. 目标人群
```
输入目标人群，按回车添加
例如：
- 跑步爱好者
- 减脂人群
- 马拉松备赛者
- 运动新手
```

## 📄 课程内容格式

### Markdown 格式要求

```markdown
# 主标题（课程名称）

> 简短描述或引言

## 一、第一部分

### 1.1 小节标题

内容...

### 1.2 小节标题

内容...

## 二、第二部分

### 2.1 小节标题

...
```

### 支持的 Markdown 元素

- ✅ 标题（# ## ### #### ##### ######）
- ✅ 段落和换行
- ✅ 列表（有序和无序）
- ✅ 表格
- ✅ 代码块
- ✅ 引用
- ✅ 加粗和斜体
- ✅ 链接和图片

## ✨ 增强版特性

系统会自动处理：

### 1. 保留标题层级结构
```
原始：
# 心率区间训练法
## 五区心率训练法
### Zone 2 - 有氧基础区

处理后：
层级 1: 心率区间训练法
层级 2: 五区心率训练法
层级 3: Zone 2 - 有氧基础区
```

### 2. 生成面包屑导航
```
Zone 2 - 有氧基础区
↓
面包屑: 心率区间训练法 > 五区心率训练法 > Zone 2 - 有氧基础区
```

### 3. 提取关键概念
```
标题: Zone 2 - 有氧基础区（60-70%）
↓
关键概念: ["Zone 2", "有氧", "60-70%", "燃脂"]
```

### 4. 智能分块
- 分块大小：1800-2000 字符
- 优先按小标题分割
- 保持知识点完整性
- 添加重叠上下文

### 5. 智能分类
自动识别课程内容类型：
- 心肺训练 (cardio_training)
- 力量训练 (strength_training)
- 运动生理学 (exercise_physiology)
- 营养补给 (nutrition)
- 恢复策略 (recovery)
- 体重管理 (weight_management)
- 目标设定 (goal_setting)
- 损伤预防 (injury_prevention)
- 运动表现 (performance)

## 🚀 上传流程

### 步骤 1: 准备内容

将张展晖课程的 Markdown 文件内容复制到剪贴板

### 步骤 2: 填写表单

1. **课程标题**: `心率区间训练法`
2. **作者**: `张展晖`
3. **来源标识**: `zhang_zhanhui_01`
4. **难度级别**: `中级 (Intermediate)`
5. **目标人群**: 
   - 输入 `跑步爱好者` → 回车
   - 输入 `减脂人群` → 回车
   - 输入 `运动爱好者` → 回车
6. **课程内容**: 粘贴 Markdown 内容

### 步骤 3: 预览信息

- 查看字符数统计
- 确认预计生成的文档块数量
- 检查表单是否完整

### 步骤 4: 点击上传

点击 **🚀 上传课程** 按钮

### 步骤 5: 等待处理

- 系统会显示"上传中..."
- 处理时间取决于内容大小（通常 10-30 秒）
- 不要关闭页面或刷新

### 步骤 6: 确认成功

上传成功后会弹出提示：
```
✅ 课程上传成功！

添加了 12 个文档块
向量化了 12 个文档
```

4. 查看 AI 是否结合课程内容回答

## ⚠️ 常见问题

### Q1: 上传失败，提示"权限不足"

**解决方案**: 确保使用管理员账号登录

### Q2: 上传超时

**可能原因**:
- 文件太大（>100KB）
- 网络问题
- OpenAI API 调用慢

**解决方案**:
- 将大文件拆分成多个小文件
- 检查网络连接
- 稍后重试

### Q3: 上传成功但搜索不到

**解决方案**:
- 等待几秒让向量化完成
- 刷新统计页面确认文档数量
- 检查搜索关键词是否准确

### Q4: 文档被分成太多块

**解决方案**:
- 检查 Markdown 结构，减少不必要的小标题
- 合并相关内容到同一节
- 系统会自动优化分块，通常不需要手动调整

### Q5: 如何删除已上传的课程

**方法 1**: 按来源删除
- 使用 API: `DELETE /knowledge/documents/source`
- 提供 source 参数（如 `zhang_zhanhui_01`）

**方法 2**: 清空整个知识库
- 在统计概览页面点击 **🗑️ 清空知识库**
- ⚠️ 此操作不可恢复，请谨慎使用
