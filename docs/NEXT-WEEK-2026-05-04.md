## 五、风险点

### 🔴 最大风险: Doctor weekly 合规 tone

明早 09:15 看到文案如果有诊断性语言（"你应该去看医生" / "你得了 X" / "建议服用 Y"），
立即：
1. 关 `celery_app.py:176` 的 `doctor-weekly-report` beat（临时停推）
2. 改 `notifications.py` 的 prompt 和关注点措辞
3. 手动触发 `regenerate_briefing_for_user` 测新文案
4. 改好再重开 beat

**合规是红线**, 一次文案失误值得暂停整条线.

### 🟡 次风险: silent fail 观察不到

- **Open-Loop Manager 如果一条都没推**（没人中阈值），你以为它在跑其实它空转. 至少第 3 天 SQL 查确认有 `open_loop_history` 行
- **Clinical Journal briefing 如果 except 被 swallow**（fail-soft 设计），journal 表空而你不知道. 同理 SQL 查

### 🟢 可接受风险

- 用户误删 / 误操作导致的 ActionCard 状态乱 → 观察期没事, 数据积累再考虑
- Garmin session 过期 → 已经 24h 监控, 会报
