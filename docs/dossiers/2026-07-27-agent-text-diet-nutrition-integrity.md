## S0 · 用户需求（逐字）

> 没有计算热量和营养成分，只记录了文本内容，分析原因并解决

生产失败原句：

```text
记录早餐，吃了一个包子、一个茶叶蛋、一碗粥，计算热量和营养成分。
```

Agent 返回了 verified 饮食回执，但记录和饮食卡均为 0 kcal、0 g
蛋白质，数据库营养字段实际为空。

## S1 · 根因

1. `simple_health_record` 的食物提取把尾部“计算热量和营养成分”保留在
   `food_items`。
2. Goal Guard 只在模型餐次与食物身份完全等价时保留模型营养估算。模型返回的
   是干净食物名称，与带分析指令的权威字符串不一致，因此估算被丢弃。
3. `health_record` 校验仅要求饮食有 `food_items`，允许
   `source=agent_text` 的空营养记录落库。
4. 模型可以省略或伪造 `source=manual` 绕过来源限定；图片预写失败后的模型回退
   也存在同类空营养风险。
5. 相邻排查发现饮水意图使用单字“水”，会把“碳水”和“水饺”误路由到饮水。

生产只读核验确认记录 `#902` 的来源为 `agent_text`，营养字段为空。核验过程未
读取或记录用户健康正文。

## G1 · 准入裁决

- classification: reliability restoration
- first_class_objects: `GoalSpec`、`WriteIntent`、verified diet receipt
- core_loop_step: explicit meal observation -> estimated nutrition -> verified write
- target_surface: Agent Backend source of truth；Mobile/Mac/Web 共用
- safety_level: L3 health data
- autonomy_tier: 当前轮明确写入意图；不扩大自治范围
- success_metric: 文本餐食只在热量与宏量营养完整时取得 verified receipt
- **裁决：PASS。** 恢复既有 Agent Native 饮食记录闭环。

## G2 · 可行性与风险压测

- 分析指令仅在食物尾部、带计算或分析动词时移除，不删除“低热量沙拉”等食物
  自身描述。
- 模型营养估算仍仅在餐次和归一化食物身份一致时保留，防止把其他餐的营养写入。
- 只有 Agent 文本或附件来源的饮食写入要求完整
  `calories/protein/carbs/fat/fiber`，不改变独立手工录入和历史数据契约。
- 来源由服务端根据当前 Turn 锁定，模型不能伪装成手工录入；图片已预写时只回放
  已验证回执，图片预写失败时模型回退仍受完整营养约束。
- 缺失营养或 0 kcal 在 ToolGateway dispatch 前拒绝，不创建空壳记录。
- 布尔值、NaN、正负无穷与越界营养值均在 dispatch 前拒绝。
- 非零热量但蛋白质、碳水和脂肪全部为零的空壳估算同样拒绝；明确
  `alcohol_units > 0` 的纯酒精热量保留合法例外。
- 饮水路由使用明确饮水词和查询短语，不再使用单字“水”。
- “一杯水／500ml 水”等常用写法继续命中饮水，同时“水果茶／水果汁／水果沙拉”
  不会因量词子串误判。
- 可恢复参数拒绝后，模型可以自然追问缺失信息，但没有 verified receipt 时不得
  声称记录、保存、更新、删除或同步成功；多模型面板也不得覆盖该拒绝。
- 无数据库迁移，无客户端契约变化。
- **裁决：PASS。**

- [x] 连续修复达到轮次上限时返回最后一个明确校验原因，不再泛化成模型失败。
- [x] 区分图片已保存后的回执重放与图片保存失败后的完整营养回退。
- [x] 拒绝布尔值、NaN、Inf 等不可持久化营养值。
- [x] 拒绝非零热量加全零宏量营养，并保留明确酒精摄入例外。
- [x] 阻止无回执的模型成功文案及多模型综合覆盖真实拒绝。
- [x] 保留参数缺失时的正常追问，不把澄清交互误判成系统失败。
- [x] 修复“一杯水”与“一杯水果茶”等相邻词边界。
- [x] 保持 Runtime 饮食幂等身份不含营养估算，重算不会产生第二次副作用。
- [x] 修参成功后清除同一写入槽位的旧拒绝，不再出现“先失败、后成功仍报错”。
- [x] 仅允许后续轮次的修参成功清除旧拒绝；同轮其他成功写入不能吞掉失败。
- [x] 同文案的多个独立失败逐项展示，不按错误文案错误合并。
- [x] 保守识别“一个包子”与“包子 1 个”等量词前后置同餐表达。
- [x] validator 自身异常时 fail-closed，不执行未经校验的健康工具调用。
- [x] 营养拒绝日志只记录原因状态，不记录用户热量值。
