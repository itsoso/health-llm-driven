## 可重复巡检

在仓库根目录执行：

```bash
node frontend/scripts/audit-navigation.cjs --out /tmp/web-page-audit.json
node frontend/scripts/audit-navigation.cjs --base-url http://127.0.0.1:30123 --out /tmp/web-page-audit-local.json
cd frontend
npm test -- src/components/navigationRoutes.test.ts
```

HTTP 巡检使用至多三个并发、请求超时、有限同源跳转，不发送 cookie，不保存页面正文。发现问题时真实返回非零退出码；它只验证匿名入口，业务验收需要登录状态、来源与交互证据。
