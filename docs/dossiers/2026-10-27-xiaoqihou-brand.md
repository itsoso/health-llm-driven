# 小气候名称与图标更新

日期：2026-10-27

## 范围与状态

用户选择将现有 App 更名为「小气候」，优化图标，并准备中国大陆文字商标申请。本次仅更换品牌展示和资源，不改变健康功能、同意流程、权限、用户隔离、Bundle ID、EAS 项目或版本策略。

- App Store Connect：现有 App 6763569720 的可编辑 en-US 名称已保存并读回为「小气候」，状态 PREPARE_FOR_SUBMISSION。证据：`docs/reviews/2026-10-27-xiaoqihou-name-receipt.json`。未提交审核，未公开发布。
- 客户端：名称常量、登录/锁屏、分享展示、原生配置、Watch 配置生成器和商店预检同步；图标采用米白底、绿色环抱轮廓与橙色圆点，源图保存在 `docs/design/xiaoqihou/app-icon-concept-v2.png`。
- 商标：尚未申请、缴费或取得权利。国内自然人申请所需经营资格材料尚不具备，申请人个人资料不进入仓库。待真实具备资格或明确选择合格主体后，再完成类别、近似检索与申请材料。

## 验证证据

- 先更新名称/背景断言：4 个套件、7 条断言按预期失败；实现后修复。
- 22 个相关 mobile 套件合计 566 条测试通过（初次运行唯一旧名称正则失败，修正后其 15 条测试全部通过）；隐私页面另 2 条通过。
- Mobile `npx tsc --noEmit`、`npm run design:check` 通过。
- 两个商店预检脚本通过；对应 Python 元数据测试 69 条通过。测试采用 SQLite 内存环境，仅验证配置与文档，不涉及数据库行为变更。
- System Map 校验、差异空白检查通过；无架构结构变化。
- 独立安全审查确认隐私文案仅替换名称，原同意和披露语义保留；发现提交资料仍有 ready 状态会被最终提交检查读取，已改为 preparing，保留闸阻断，修正后重审。

## 发布边界和断点

原生名称与图标需要新安装包，不能通过 OTA 宣称完成。当前旧版安装包、历史截图和已选商店 build 不构成本次更名验收；新原生候选必须重新完成模拟器验收、候选绑定资料与商店检查。未发起新原生构建或商店送审；不得把名称保存等同于公众可见更新或商标注册。本次没有后端业务代码变化。

工作区已有其他任务的发布记录和 benchmark 修改，仅暂存本任务变更；submission-pack 的既有修改保留在工作区。
