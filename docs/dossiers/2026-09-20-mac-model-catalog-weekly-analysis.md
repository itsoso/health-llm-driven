# Mac 模型目录与本周分析修复

## 范围与根因

- Mac 模型菜单读取安装包内固定目录，无法跟随服务端可用/披露模型变化；“当前使用”实际取的是上次回答元数据，不是本次手动选择。
- “分析本周的饮食和睡眠”在所有权检查中把分析修饰语误当成所有人；日历解析也缺少整周窗口。
- 本次只修复、验证并进行安全复审；不包含生产部署、签名安装包发布或替换本机已安装应用。

## 实现边界

- Mac 使用现有认证接口 `GET /me/llm-preference` 的 options，完整替换目录，空列表不恢复已下线模型。不增加管理员接口或新依赖，不修改服务端用户偏好。
- 打开聊天和前台激活时刷新，菜单支持手动刷新；同一 ViewModel 刷新请求去重。失败保留旧目录并明确提示，保留用户选择，目录已无该模型时提示重新选择。
- 菜单标注“上次回答模型”，不把内部快速工具路由误标为本次选择。保留现有首轮工具快速路由策略。
- 只在所有权解析内归一化开头的分析/复盘/总结请求修饰语；日期、所有人、否定、引用、过滤条件仍由原有权限与范围检查裁决。
- 本周/这周为用户时区的周一至今天；上周为上周一至周日。混合日期、不支持的限定条件不获得默认七天授权。睡眠继续沿用醒来日期归属。
- 无数据库迁移、凭证、生产健康记录或权限扩大。
