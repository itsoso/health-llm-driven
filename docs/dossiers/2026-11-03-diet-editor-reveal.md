## 实现与边界

聊天列表通过局部 React context 提供可取消的定位请求。点击展开时先停止自动追随和旧滚动重试，等待编辑器原生节点挂载并测量，按编辑器与聊天视口的坐标滚到编辑器起始处；已完整可见时保持位置。定位到目标表单，不滚到整个会话末尾。

仅显式点击展开触发；加载已展开的历史卡片不触发。手动拖动、状态栏回顶、跳到最新、离开页面、切换对话、进入后台、收起/保存表单或目标卸载会取消待执行定位。晚到的原生测量回调不能覆盖新的滚动意图。跟踪所有原生滚动位置，但仅手势事件改变既有滚动意图。
