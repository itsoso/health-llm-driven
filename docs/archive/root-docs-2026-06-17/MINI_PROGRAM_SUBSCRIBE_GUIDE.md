# 小程序订阅提醒设置指南

## 📱 操作步骤

### 第一步：进入设置页面

1. 打开小程序
2. 点击底部导航栏的 **"我的"** 标签页
3. 在页面中找到 **"消息提醒"** 模块

### 第二步：开启订阅提醒

#### 情况 A：首次开启（未订阅过）

1. 点击 **"开启消息提醒"** 按钮
2. 系统会弹出微信订阅消息授权弹窗
3. 选择要订阅的消息类型：
   - ✅ **健康提醒** - 喝水、洗鼻、运动等定时提醒
   - ✅ **早间简报** - 每日健康数据摘要
   - ✅ **健康预警** - 健康异常情况提醒
   - ✅ **目标进度** - 目标完成情况通知
   - ✅ **周报通知** - 每周健康报告
4. 点击 **"允许"** 完成授权

> ⚠️ **注意**：
> - 微信限制每次最多请求 3 个模板，如果模板超过 3 个，会分批弹出授权窗口
> - 如果用户拒绝某个模板，该模板在 7 天内不会再弹窗
> - 建议在用户主动操作时（如点击按钮）请求授权，避免在页面加载时自动弹出

#### 情况 B：已订阅过

如果已经订阅过，页面会显示：

1. **消息通知开关** - 可以快速开启/关闭所有通知
2. **已订阅数量** - 显示当前已订阅的模板数量（如 "5项"）
3. **添加更多订阅** - 可以添加新的订阅模板

### 第三步：管理订阅设置

#### 开启/关闭通知总开关

- 在 **"消息通知"** 右侧有一个开关
- 打开开关：接收所有已订阅的通知
- 关闭开关：暂停接收所有通知（但订阅关系保留）

#### 添加更多订阅

1. 点击 **"添加更多订阅"** 按钮
2. 系统会再次弹出授权窗口
3. 选择要新增的订阅类型
4. 点击 **"允许"** 完成授权

## 🔔 订阅的消息类型说明

### 1. 健康提醒 (HEALTH_REMINDER)
- **用途**：定时提醒用户完成健康任务
- **示例**：
  - 喝水提醒（如：每天 8:00、12:00、18:00）
  - 洗鼻提醒（如：每天 7:00、19:00）
  - 运动提醒（如：每天 18:00）
  - 服药提醒（如：每天 8:00、20:00）

### 2. 早间简报 (MORNING_BRIEFING)
- **用途**：每日早晨推送健康数据摘要
- **内容**：
  - 昨日睡眠质量
  - 今日运动建议
  - 健康指标变化
  - 个性化问候语
- **发送时间**：默认 07:30（可在后端配置）

### 3. 健康预警 (HEALTH_ALERT)
- **用途**：当检测到健康异常时推送
- **触发条件**：
  - 心率异常（过高/过低）
  - 血压异常
  - 睡眠质量严重下降
  - 其他健康指标异常

### 4. 目标进度 (GOAL_PROGRESS)
- **用途**：提醒用户目标完成情况
- **示例**：
  - 步数目标完成度
  - 运动时长目标
  - 体重管理目标
  - 其他自定义目标

### 5. 周报通知 (WEEKLY_REPORT)
- **用途**：每周推送健康数据总结
- **内容**：
  - 本周运动统计
  - 睡眠质量趋势
  - 健康指标变化
  - 下周建议

## ⚙️ 技术实现细节

### 前端实现

订阅提醒功能位于：
- **页面**：`packages/mini-program/src/pages/settings/index.tsx`
- **服务**：`packages/mini-program/src/services/subscribe.ts`

### 核心功能

1. **`requestAllSubscriptions()`** - 请求所有推荐的订阅模板
2. **`requestSubscribe(templateKeys)`** - 请求指定模板的订阅
3. **`saveSubscribeSettings()`** - 保存订阅设置到后端
4. **`getSubscribeSettings()`** - 获取当前订阅设置

### 后端 API

- **GET** `/api/wechat/subscribe/settings` - 获取订阅设置
- **POST** `/api/wechat/subscribe/settings` - 保存订阅设置
- **PUT** `/api/wechat/subscribe/settings` - 更新通知设置（开关、时间等）

## 🚨 常见问题

### Q1: 为什么点击"开启消息提醒"没有反应？

**A**: 可能的原因：
1. 模板 ID 未配置 - 检查 `subscribe.ts` 中的 `TEMPLATE_IDS` 是否已配置
2. 微信版本过低 - 订阅消息功能需要微信 7.0.6+ 版本
3. 小程序未发布 - 订阅消息功能需要在正式版小程序中使用

### Q2: 用户拒绝订阅后，如何重新开启？

**A**: 
- 如果用户拒绝了某个模板，该模板在 7 天内不会再弹窗
- 7 天后可以再次点击"添加更多订阅"重新请求授权
- 或者用户可以在微信小程序设置中手动开启

### Q3: 订阅后没有收到消息？

**A**: 检查以下几点：
1. **通知总开关** - 确认"消息通知"开关已打开
2. **微信通知权限** - 确认手机微信已开启小程序通知权限
3. **订阅状态** - 在设置页面查看"已订阅"数量，确认订阅成功
4. **后端推送** - 确认后端已正确配置推送服务并发送消息

### Q4: 可以只订阅部分消息类型吗？

**A**: 可以！
- 在授权弹窗中，用户可以选择性地允许或拒绝某些模板
- 只允许的模板会被订阅，拒绝的不会订阅
- 后续可以通过"添加更多订阅"补充其他类型

### Q5: 订阅设置保存在哪里？

**A**: 
- 订阅设置保存在后端数据库的 `user_notification_settings` 表中
- 字段 `wechat_template_ids` 存储用户已订阅的模板 ID 映射
- 前端会从后端获取订阅状态并显示

## 📋 最佳实践

### 1. 请求订阅的时机

✅ **推荐**：
- 用户主动点击"开启消息提醒"按钮时
- 用户完成某个操作后（如完成打卡），提示开启下次提醒
- 在设置页面提供明确的订阅入口

❌ **不推荐**：
- 页面加载时自动弹出（用户体验差）
- 用户未操作时弹出（可能被拒绝）

### 2. 订阅模板的选择

- **首次订阅**：建议请求所有 5 种模板，让用户了解完整功能
- **后续补充**：用户可以根据需要添加特定类型的订阅

### 3. 用户体验优化

- 提供清晰的说明文字，告诉用户订阅的好处
- 显示已订阅的数量，让用户了解当前状态
- 提供总开关，方便用户快速开启/关闭所有通知

## 🔧 开发者注意事项

### 1. 模板 ID 配置

- 模板 ID 需要在微信公众平台申请
- 申请路径：微信公众平台 -> 功能 -> 订阅消息 -> 选用模板
- 申请后需要将模板 ID 配置到 `TEMPLATE_IDS` 中

### 2. 微信限制

- 每次最多请求 3 个模板
- 用户拒绝后，同一模板 7 天内不会再弹窗
- 订阅消息需要用户主动触发（不能自动弹出）

### 3. 后端推送

- 订阅成功后，后端需要调用微信 API 发送订阅消息
- 推送代码位于 `backend/app/services/wechat_push.py`
- 需要配置 `WECHAT_APPID` 和 `WECHAT_SECRET`
