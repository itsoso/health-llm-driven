# 智能饮食推荐系统 Phase 2 - 功能说明

## 🎉 Phase 2 新增功能

### 1. 健康状态整合

系统现在会自动获取并分析用户当天的健康数据：

```json
{
  "health_status": {
    "sleep_score": 84,        // 睡眠评分 (0-100)
    "sleep_hours": 7.5,       // 睡眠时长
    "body_battery": 75,       // 身体电量 (0-100)
    "stress_level": 35,       // 压力水平 (0-100)
    "resting_hr": 47,         // 静息心率
    "hrv": 65                 // 心率变异性
  }
}
```

### 2. 智能警告系统

根据用户的营养摄入、健康状况和目标，系统会生成个性化警告：

#### 营养摄入警告
- ⚠️ 蛋白质摄入不足（<50%目标）
- ⚠️ 卡路里超标（>120%目标）
- ⚠️ 碳水摄入过高（减重模式下）

#### 健康状况警告
- 🩺 高血压：控制钠摄入 <2000mg/天
- 🩺 糖尿病：控制碳水总量，选择低GI食物
- 🚫 过敏提醒：自动排除过敏源食物

**示例：**
```json
{
  "warnings": [
    "⚠️ 今日蛋白质摄入不足，建议补充优质蛋白质",
    "🩺 注意控制钠摄入（<2000mg/天），少吃腌制食品",
    "🚫 过敏提醒：避免 海鲜, 花生"
  ]
}
```

### 3. 个性化健康提示

基于实时健康数据提供针对性建议：

#### 睡眠相关（睡眠评分 < 70）
- 💤 睡眠质量欠佳，建议晚餐清淡，避免咖啡因
- 🥛 可以喝一杯温牛奶或吃一根香蕉，有助于睡眠

#### 压力相关（压力水平 > 50）
- 😌 压力较大，建议多吃深绿色蔬菜和坚果，补充镁元素
- 🍵 避免高糖食物，可以喝绿茶或花茶舒缓压力

#### 能量相关（身体电量 < 30）
- ⚡ 身体电量较低，建议补充优质碳水和蛋白质恢复能量

#### 体重目标相关
- 🎯 减重模式：优先选择高蛋白低脂食物，增加饱腹感
- 🎯 增重模式：增加优质蛋白和健康脂肪摄入

**示例：**
```json
{
  "tips": [
    "💤 睡眠质量欠佳，建议晚餐清淡，避免咖啡因",
    "🎯 减重模式：优先选择高蛋白低脂食物，增加饱腹感",
    "💧 记得多喝水，保持充足水分"
  ]
}
```

### 4. 具体食物推荐

系统会根据剩余营养需求、健康状态和饮食限制，推荐具体食物：

#### 推荐分类
1. **优质蛋白**（蛋白质不足 >50g）
2. **碳水化合物**（碳水不足 >50g）
3. **健康脂肪**（脂肪不足 >20g）
4. **蔬菜**（维生素和纤维）
5. **水果**（维生素C和抗氧化物）
6. **餐次特定推荐**（早餐/晚餐）

**示例：**
```json

    {
      "category": "蔬菜",
```

## 🧠 智能推荐逻辑

### 1. 过敏源自动过滤

系统会自动排除用户的过敏源：

| 过敏源 | 排除食物 |
|--------|----------|
| 海鲜 | 三文鱼、鳕鱼、虾 |
| 牛奶 | 牛奶、酸奶、奶酪 |
| 花生 | 花生、花生酱 |
| 坚果 | 核桃、杏仁、腰果 |

### 2. 饮食偏好适配

#### 素食模式 (vegetarian)
- 蛋白质来源：豆腐、豆浆、鹰嘴豆、藜麦
- 排除：所有肉类和海鲜

#### 低碳水模式 (low_carb)
- 碳水来源：糙米饭、燕麦、红薯、全麦面包
- 避免：白米饭、白面条、精制糖

#### 生酮模式 (keto)
- 碳水来源：西兰花、菠菜、生菜、黄瓜
- 极低碳水：<26g/天

### 3. 慢性病饮食限制

#### 高血压
- ⚠️ 限制钠摄入 <2000mg/天
- ✅ 推荐：DASH饮食，增加钾摄入（香蕉、土豆）

#### 糖尿病
- ⚠️ 控制碳水总量和GI值
- ✅ 推荐：高纤维食物，分餐制

### 4. 餐次特定推荐

#### 早餐 (breakfast)
```json
{
  "category": "早餐推荐",
  "foods": ["燕麦粥", "全麦面包", "鸡蛋", "牛奶", "香蕉"],
  "reason": "开启一天的能量，营养均衡",
  "priority": "high"
}
```

#### 晚餐 (dinner)
```json
{
  "category": "晚餐推荐",
  "foods": ["清蒸鱼", "蔬菜沙拉", "豆腐汤", "糙米饭"],
  "reason": "晚餐宜清淡，避免过饱影响睡眠",
  "priority": "high"
}
```

## 🧪 测试场景

### 场景 1: 减重用户 + 睡眠不佳

**用户状态：**
- 体重目标：减重
- 睡眠评分：65
- 今日蛋白质不足

**系统响应：**
- ⚠️ 蛋白质摄入不足警告
- 💤 睡眠质量欠佳，推荐助眠食物
- 🎯 减重模式饮食建议
- 推荐：鸡胸肉、香蕉、牛奶

### 场景 2: 高血压患者 + 压力大

**用户状态：**
- 慢性病：高血压
- 压力水平：60
- 过敏源：海鲜

**系统响应：**
- 🩺 控制钠摄入警告
- 😌 压力大，推荐抗压食物
- 🚫 排除所有海鲜
- 推荐：深绿色蔬菜、坚果、绿茶

### 场景 3: 素食增肌用户

**用户状态：**
- 饮食偏好：素食
- 体重目标：增重
- 运动频率：高

**系统响应：**
- 🎯 增重模式建议
- 推荐植物蛋白：豆腐、豆浆、鹰嘴豆、藜麦
- 推荐加餐：坚果、牛油果、全麦面包
