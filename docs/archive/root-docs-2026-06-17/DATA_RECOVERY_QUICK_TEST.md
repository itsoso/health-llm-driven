## ⚠️ 如果发现数据问题

### 情况 1: 部分数据缺失

**可能原因**: 
- 该数据的用户 ID 在迁移时不匹配（例如测试账号的数据）
- 数据在 SQLite 中就不存在

**解决方案**:
- 联系技术支持，提供具体缺失的数据信息
- 可以从 SQLite 备份中恢复特定数据

### 情况 2: 数据显示异常

**可能原因**:
- 数据类型转换问题
- 前端缓存问题

**解决方案**:
1. 刷新页面（清除缓存）
2. 重新登录
3. 如果仍有问题，联系技术支持

### 情况 3: 无法访问某些功能

**可能原因**:
- 后端服务重启中
- 数据库连接问题

**解决方案**:
1. 等待 1-2 分钟后重试
2. 检查网络连接
3. 如果仍有问题，联系技术支持
