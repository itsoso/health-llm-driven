# Debug 模式使用演示

## 🎉 功能已上线

Debug 模式已成功部署到生产环境，您现在可以直接在页面上查看 AI 的决策过程！

## 📍 访问地址

**运动前指导页面：**
https://health.westwetlandtech.com/workout-guidance

## 🔍 使用步骤

### 1. 打开运动前指导页面

访问上述链接，您会看到运动前指导的表单。

### 2. 勾选 Debug 模式

在表单底部，您会看到一个新增的复选框：

```
☑️ Debug 模式（展示 AI 决策过程）
```

勾选它即可启用 Debug 模式。

### 3. 获取运动指导

- 可以选择一个目标（可选）
- 可以选择运动类型（可选）
- 点击 **"🎯 获取运动前指导"** 按钮

### 4. 查看 Debug 信息

页面会在最上方展示一个**紫色的 Debug 面板**，包含三个部分：

#### 📋 决策步骤
展示 AI 执行的 7 个步骤：
```
1. 获取用户基本信息
2. 获取用户运动目标
3. 获取最近7天Garmin健康数据
4. 计算个性化心率区间
5. 确定运动类型
6. 从张展晖课程知识库检索相关建议
7. 生成个性化运动指导
```

#### 🧠 推理过程
展示每一步的决策依据，例如：
```
✅ 用户资料：35岁，男，体重70kg
🎯 自动选择活跃目标：提升5公里配速
📊 最近健康状态：睡眠评分85, 静息心率48bpm, HRV 65ms, 身体电量85
💓 基于年龄35岁和静息心率48bpm计算5个心率区间
   - 最大心率: 179bpm
   - 建议训练区间(Zone 2): 126-139bpm
🏃 根据目标推断运动类型：RUNNING
📚 知识库查询：进行RUNNING训练前需要注意什么？提升5公里配速
📖 从知识库检索到3条相关内容
✅ 生成完成，包含以下内容：
   - 热身建议：5条
   - 关键提醒：6条
   - 课程要点：3条
```

#### 📊 数据来源
点击 **"点击查看详细数据来源 →"** 可以展开查看完整的 JSON 数据，包括：
- 用户资料（年龄、性别、体重、身高、健身水平）
- 运动目标（标题、描述、目标值）
- 最近健康数据（睡眠、压力、心率、HRV、身体电量）
- 心率区间（5个区间的详细数值）
- 知识库查询（查询内容和检索结果）

## 💡 使用场景

### 1. 了解 AI 如何工作
通过 Debug 模式，您可以清楚地看到：
- AI 使用了您的哪些数据
- 如何计算心率区间
- 从知识库中检索了什么内容
- 为什么给出这些建议

### 2. 验证数据准确性
您可以检查：
- 用户资料是否正确
- 健康数据是否最新
- 心率区间计算是否合理
- 知识库检索是否相关

### 3. 提供反馈
如果您发现：
- 数据不准确
- 建议不合理
- 知识库内容不相关

可以截图 Debug 信息，帮助我们改进系统。

## 🎯 实际案例

### 案例 1：睡眠不足时的建议调整

**用户状态：**
- 睡眠评分：55
- 睡眠时长：5.2小时

**Debug 显示：**
```
📊 最近健康状态：睡眠评分55, 睡眠5.2小时
📚 知识库查询：进行RUNNING训练前需要注意什么？睡眠不足时如何调整训练？
```

**生成的建议：**
```
😴 昨晚睡眠不足，建议降低训练强度 20-30%
```

您可以看到 AI 检测到了睡眠不足，并自动调整了训练强度建议。

### 案例 2：压力较大时的建议

**用户状态：**
- 压力水平：75
- 身体电量：35

**Debug 显示：**
```
📊 最近健康状态：压力水平75, 身体电量35
📚 知识库查询：压力较大时如何训练？
```

**生成的建议：**
```
😌 压力较大，避免高强度训练，以恢复为主
```

## 🔧 开发者模式

如果您是开发者，Debug 模式还可以帮助您：

### 1. 验证 API 响应
查看完整的数据结构，确保所有字段都正确返回。

### 2. 调试知识库检索
查看知识库查询语句和检索结果，优化检索策略。

### 3. 分析性能
观察数据获取和处理的流程，找出性能瓶颈。

### 4. 测试不同场景
通过修改用户数据，测试不同健康状态下的建议差异。

## 📝 注意事项

1. **数据隐私**：Debug 信息包含您的个人健康数据，请勿随意分享截图
2. **性能影响**：Debug 模式会返回更多数据，响应时间可能稍长
3. **缓存策略**：Debug 模式会跳过缓存，始终生成新的分析
4. **移动端适配**：Debug 面板在移动端也可以正常显示，但建议在桌面端查看
