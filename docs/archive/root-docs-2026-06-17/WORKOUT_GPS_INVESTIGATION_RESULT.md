## 📝 用户建议

### 确保 GPS 数据记录

1. **户外运动前**:
   - 确认设备已开启 GPS
   - 等待 GPS 信号锁定（通常需要 30-60 秒）
   - 在开阔地带开始运动

2. **室内运动**:
   - 跑步机、室内骑行等室内运动**本身就没有 GPS 数据**
   - 这是正常现象，不是系统问题

3. **检查设备设置**:
   - 进入 Garmin 设备设置
   - 确认 GPS 功能已启用
   - 检查 GPS 模式（GPS、GPS+GLONASS、GPS+Galileo）

### 如何判断是否有 GPS

在 Garmin Connect APP 或网页上查看活动详情：
- ✅ 有地图显示 → 有 GPS 数据
- ❌ 无地图显示 → 无 GPS 数据

如果 Garmin Connect 上都没有地图，那么我们的系统也无法显示。

## 🔧 技术细节

### GPS 数据同步流程

```
1. 用户完成运动
   ↓
2. Garmin 设备记录数据（包括 GPS 轨迹）
   ↓
3. 设备同步到 Garmin Connect
   ↓
4. 我们的系统从 Garmin Connect 获取数据
   ↓
5. 解析并存储到数据库
   ↓
6. 前端显示地图
```

**关键点**: 如果第 2 步（设备记录）就没有 GPS 数据，后续步骤无法补救。

### 重新同步脚本

已创建脚本 `backend/scripts/resync_workout_gps.py` 用于手动重新同步 GPS 数据：

```bash
cd /opt/health-app/backend
source venv/bin/activate
python scripts/resync_workout_gps.py --user-id 3 --workout-ids 50,48
```

**功能**:
- 从 Garmin Connect 重新获取活动详情
- 解析 GPS 数据
- 更新数据库

**限制**:
- 只能获取 Garmin Connect 上已有的数据
- 无法为没有 GPS 的活动创造 GPS 数据
