## 主要变更

### ✅ 调整
1. **每日记录提前**
   - 从第二位移到第一位（紧跟今日建议）
   - 位置更靠左，方便快速点击
   - 作为高频功能，优先级提升

2. **每日复盘独立**
   - 从主导航移回下拉菜单
   - 恢复为独立的下拉菜单分组
   - 保持功能的独立性

3. **导航更紧凑**
   - 主导航只保留 3 个核心入口
   - 下拉菜单 4 个分组，层次清晰
   - 高频功能靠左排列

## 设计理念

### 1. 使用频率优先
```
高频功能 → 靠左位置
├─ 每日记录：日常打卡、记录（最高频）
├─ 健康追踪：查看数据、监测指标
├─ 每日复盘：每日总结
└─ 管理中心：设置和管理（低频）
```

### 2. 点击便利性
- **每日记录**放在第一位（今日建议之后）
- 鼠标移动距离最短
- 符合从左到右的阅读习惯

### 3. 功能分组逻辑
```
主导航（快速入口）
├─ 首页：总览
├─ 健康概览：数据总览
└─ 今日建议：AI 推荐

下拉菜单（功能分类）
├─ 每日记录：日常记录 + 数据查看 [高频]
├─ 健康追踪：各类健康指标监测 [中频]
├─ 每日复盘：每日总结 [中频]
└─ 管理中心：系统设置和管理 [低频]
```
