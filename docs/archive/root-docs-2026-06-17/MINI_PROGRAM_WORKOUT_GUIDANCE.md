# 小程序运动指导功能集成总结

> 在小程序首页添加智能运动指导入口，基于张展晖课程提供科学训练建议

## 📋 实现概述

### 核心功能

1. **首页运动卡片智能推荐**
   - 当今日无运动记录时，自动获取并展示运动指导
   - 显示训练目标和心率区间建议
   - 提供「查看完整指导」按钮跳转到详情页

2. **快捷功能区入口**
   - 将原「运动训练」改为「运动指导」
   - 点击直接跳转到运动指导页面

3. **独立运动指导页面**
   - 完整展示运动前指导信息
   - 包含身体状态、训练目标、心率区间、热身建议等

## 🎯 功能详情

### 1. 首页运动卡片增强

**位置**: `packages/mini-program/src/pages/index/index.tsx`

**逻辑**:
```typescript
// 如果今日没有运动记录，获取运动指导
if (workouts.length === 0) {
  workoutGuidance = await getPreWorkoutGuidance('running');
}
```

**UI展示**:
- **有运动记录**: 显示运动列表和总消耗
- **无运动记录 + 有指导**: 显示训练目标、心率区间、查看完整指导按钮
- **无运动记录 + 无指导**: 显示空状态提示

**样式特点**:
- 训练目标：渐变背景卡片，带🎯图标
- 心率区间：显示燃脂区范围
- 查看完整指导：紫色渐变按钮

## 🔧 技术实现

### API 集成

**新增 API 函数**: `packages/mini-program/src/services/api.ts`

```typescript
export async function getPreWorkoutGuidance(
  workoutType: string, 
  goalId?: number
): Promise<PreWorkoutGuidance | null>
```

**API 端点**: `POST /workout/pre-workout-guidance`

**请求参数**:
```typescript
{
  workout_type: string;  // 运动类型，如 'running'
  goal_id?: number;      // 可选的目标ID
}
```

### 类型定义

**新增类型**: `packages/mini-program/src/types/index.ts`

```typescript
export interface PreWorkoutGuidance {
  user_status: {
    body_battery: number | null;
    hrv: number | null;
    sleep_score: number | null;
    stress_level: number | null;
    readiness: string;
  };
  training_objective: string;
  heart_rate_zones: {
    max_heart_rate: number;
    zone2_fat_burn: [number, number];
    zone3_aerobic: [number, number];
    zone4_threshold: [number, number];
  };
  warm_up: string[];
  key_reminders: string[];
  course_insights: string[];
}
```

### 样式设计

**设计原则**:
- 卡片式布局，白色背景 + 阴影
- 渐变色强调重要信息
- 清晰的视觉层级
- 响应式间距和字体大小

**配色方案**:
- 主色调：紫色渐变 (#6366F1 → #A855F7)
- 状态色：
  - 红色 (#EF4444) - 最大心率
  - 绿色 (#22C55E) - 燃脂区
  - 蓝色 (#3B82F6) - 有氧区
  - 橙色 (#F59E0B) - 乳酸阈值区

## 📱 用户体验

### 交互流程

1. **首页查看**
   - 用户打开小程序首页
   - 如果今日无运动记录，自动展示运动指导精简版
   - 显示训练目标和心率区间

2. **查看详情**
   - 点击「查看完整指导」按钮
   - 或点击快捷功能区的「运动指导」
   - 跳转到运动指导详情页

3. **详细指导**
   - 查看完整的身体状态评估
   - 了解详细的心率区间
   - 阅读热身建议和关键提醒
   - 学习课程要点

4. **开始训练**
   - 点击「开始训练」按钮
   - 返回首页或跳转到运动记录页面

### 优化点

1. **性能优化**
   - 仅在无运动记录时调用运动指导 API
   - 使用 Promise.allSettled 并发加载数据
   - 避免重复请求

2. **用户体验**
   - 加载状态提示
   - 错误处理和重试机制
   - 平滑的页面过渡动画

3. **视觉设计**
   - 清晰的信息层级
   - 色彩编码的心率区间
   - 渐变背景增强视觉吸引力

```
首页加载
  ↓
获取今日运动记录
  ↓
判断是否有运动记录
  ↓
  ├─ 有记录 → 显示运动列表
  └─ 无记录 → 调用运动指导 API
              ↓
         获取运动指导数据
              ↓
         显示训练目标和心率区间
              ↓
    用户点击「查看完整指导」
              ↓
         跳转到运动指导页面
              ↓
         展示完整指导信息
```
