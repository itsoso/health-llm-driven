## ⚠️ 常见问题

### 问题 1: 编译后还是显示空白

**原因**: 可能是缓存问题

**解决方法**:
1. 点击微信开发者工具菜单栏 `项目` → `清除缓存`
2. 选择"清除全部缓存"
3. 重新编译

### 问题 2: 控制台没有日志输出

**原因**: 可能是 Console 过滤器设置问题

**解决方法**:
1. 打开 Console 面板
2. 确保没有过滤器（Filter 输入框为空）
3. 确保日志级别选择了"All"或"Info"

### 问题 3: 还是提示"还没有添加补剂"

**原因**: 可能是 Token 过期或 API 请求失败

**解决方法**:
1. 查看 Console 是否有错误日志
2. 查看 Network 面板，检查 API 请求状态
3. 如果是 401 错误，需要重新登录
4. 如果是 404 错误，检查 API 路径是否正确
