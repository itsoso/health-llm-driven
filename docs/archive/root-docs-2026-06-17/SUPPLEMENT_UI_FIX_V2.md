# 小程序补剂推荐 UI 优化 (v2)

## 优化内容

### 1. 按钮位置调整
- **取消悬浮**: 按钮不再固定在底部，而是跟随页面内容滚动。
- **布局优化**: 将按钮容器移入 `ScrollView` 底部，作为列表的一部分。
- **页面布局**: 采用 Flex 布局，`ScrollView` 自动填充剩余空间。

### 2. 文案修改
- **主标题**: "益家知研 AI 推荐" → "科学推荐"
- **加载文案**: "益家知研分析中..." → "科学分析中..."

### 3. 样式调整
- **容器间距**: 增加按钮容器的上下间距 `padding: 40rpx 0 60rpx 0`。
- **滚动区域**: `ScrollView` 高度改为 `flex: 1`，确保在不同屏幕尺寸下都能正确显示。

## 修改文件

- `packages/mini-program/src/pages/supplements/index.tsx`
- `packages/mini-program/src/pages/supplements/index.scss`

## 验证方法

1. 重新编译小程序。
2. 进入补剂页面。
3. 确认按钮不再悬浮在底部，而是需要滚动到底部才能看到。
4. 确认按钮文案已更新为"科学推荐"。
