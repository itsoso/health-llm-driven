## 🐛 常见问题排查

### 问题 1: 小程序显示"还没有添加补剂"

**可能原因**:
- Token 过期或无效
- API 请求失败
- 数据格式解析错误

**排查步骤**:
1. 打开微信开发者工具控制台
2. 查看是否有错误日志
3. 检查 Network 面板，查看 API 请求状态
4. 查看是否有 401 错误（需要重新登录）

**解决方法**:
```typescript
// 查看控制台输出
[补剂数据] 加载成功: [...]  // 应该有这个日志

// 如果没有，检查 token
const token = Taro.getStorageSync('access_token');
console.log('Token:', token);  // 应该有值

// 如果 token 为空，需要重新登录
```

### 问题 2: Web 端和小程序数据不一致

**可能原因**:
- 缓存问题
- 不同账号登录
- 网络延迟

**排查步骤**:
1. 确认两端登录的是同一个账号
2. 刷新页面（Web 端）
3. 下拉刷新（小程序端）
4. 检查网络连接

**解决方法**:
- Web 端: 按 `Ctrl+Shift+R` 强制刷新
- 小程序: 下拉页面刷新

### 问题 3: 操作后数据没有更新

**可能原因**:
- API 请求失败
- 前端状态未刷新
- 后端数据未保存

**排查步骤**:
1. 查看是否有成功提示（Toast）
2. 检查控制台错误日志
3. 手动刷新页面

**解决方法**:
```typescript
// 操作后应该有这些日志
Taro.showToast({ title: '添加成功', icon: 'success' });
// 或
Taro.showToast({ title: '操作失败', icon: 'none' });
```

### 问题 4: 科学推荐加载很慢

**正常现象**: 科学推荐需要调用 AI 分析，通常需要 3-10 秒。

**优化建议**:
- 显示加载动画
- 提示用户等待
- 后续可以考虑缓存推荐结果
