## 实现与边界

- **空结果结束**：只在完整闭合的本人睡眠/饮食请求、认证 owner 和范围一致、所有读取均有完整空结果证据时，省去回答轮模型调用。附件、待确认写入、同步、部分/失败/超范围结果等不命中。仍通过 Pi、Gateway、原事实摘要、输出护栏及持久化。
- **P2 预规划**：沿用已有 eval 候选，由服务端已绑定的 OwnedReadScope 产生规范工具提案，再交原 Gateway 执行，省去第一个模型规划轮。没有直连数据库或放宽权限；不压缩公共/写工具说明。本轮有数据、空数据和失败均有独立 API 证据。
- **证据字段共享**：仅在 provider 的 verified evidence 投影内，把重复 unknown_fields 字典提取到查询内的列表，逐行引用；known_fields、顺序、同名记录、null 状态及原始精度均保留。单行或计入解码说明后无字节收益时保持原文；未知结构原样返回。不修改执行结果、Pi transcript 或安全权威。

三项没有叠加测试或组合启用。性能预算、异常可见性、工具/模型调用上限和原 oracle 均保留。

1. [P2 初始有数据批次](2026-10-07-read-preplan-live.json)：首条 Flash baseline 触发营养推断护栏，整批停止，P2 未执行。

3. [查询措辞批次](2026-10-07-read-preplan-lookup-live.json)：首条 baseline 未命中 OwnedReadScope，Gateway 使用通用 read_only_tool，参数仅 days，通用读取依赖实际日期，与评测冻结日期不一致。保留为场景不匹配失败，不能据此断言生产丢数据，也不能算 P2 通过。

为定位后续 BLOCK，新增 **仅合成评测** 的 answer-stage 可见 content 留证，最多 16000 字符、显式截断，排除 reasoning 事件、工具阶段、请求和异常原文；事件流与用户最终回答保持原样。截断标记为 false 不代表调用成功，必须同时看样本/调用状态。[新诊断批](2026-10-07-read-preplan-diagnostic-live.json) 4 条均通过独立语义审查，但不替代或解释旧失败，也无法补回旧原答。
