# Web 助理头像与晚餐回顾查询

> Status: implementation verified locally; production verification pending
> Updated: 2026-10-29

工程维护：Web 聊天头像复用现有小气候 BrandIcon，替换遗留“巴”字。饮食查询复用现有单日读取计划和认证网关，不增加接口或写操作。

“晚餐吃了啥”“晚饭吃了什么”等完整本人回顾句，在未指定日期时按当前账号时区和冻结时间绑定当天晚餐；明确日期仍优先。不得沿用最近一次有数据的日期，也不能扩大为全天饮食。查询无记录必须如实返回无记录，不能冒充查询失败或过去餐食。时间提示由既有单日计划输出。

只接受完整限定句和现有建议后缀；引用、假设、否定、他人主体、追加写操作或未知日期限定均不从该适配器获得默认日期。模型传入的日期和餐次仍由服务端计划绑定，认证账号隔离不变。

验证：原句和同义表述先红再绿；覆盖显式日期、跨时区日期、拒绝边界、单/多模型 Pi 循环和空结果。PostgreSQL 通过真实认证接口验证只返回本人指定日期晚餐，不返回当天午餐、前一天晚餐或他人记录。Web 沿用品牌图标组件，聊天时间和导航回归通过。
