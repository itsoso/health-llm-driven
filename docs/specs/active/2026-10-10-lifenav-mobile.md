# 周导航完整 Mobile 版本

沿用 [原生整合规格](2026-10-10-navlife-native-integration.md) 的个人规划对象、认证和手动确认边界。用户要求「增加mobile 版本」，目标是解除完整编辑依赖 Web 的限制。

今日、周计划、时段导航、周复盘、成果、方向与季度、机会、备份全部使用原生 React Native 控件。今日与周计划引用相同任务；主任务每天最多一项、辅助最多两项；任务编辑、复盘应用、归档、导入和恢复均明确确认。保存使用现有 expected_revision；冲突保留草稿。前后台和账号变化清除敏感展示、拒绝晚响应。

方向与季度支持现有字段；机会保留证据、假设、适配、风险及结果，不生成健康或收益结论。时段计时使用绝对截止时间，不把后台停留当作任务完成。复盘草稿只取实际记录并保留人工填写。

备份可导出已保存数据或明确标记的本地草稿。通过系统文件选择器导入，校验大小、完整结构和日期/编号关系后先预览，再以当前 revision 确认覆盖；历史恢复创建新版本。临时规划文件在分享/解析结束后清除；不导出 Health 引用、用户标识或凭据。

复用现有 API 和已安装文件/分享模块，无数据库、后端契约或原生依赖变化，可走可信 OTA。验证覆盖八视图、同源任务、手动保存、冲突、会话切换、背景计时、严格导入、文件清理及恢复 CAS；另跑 Mobile 全量 Jest、TypeScript 和精确 SHA CI。模拟器验收与 OTA 发布回执分别记录。
