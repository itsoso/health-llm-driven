## 决策与准入

本批补齐已获准入的个人规划工作区的完整 Web 使用动线。参考 https://throws-heater-beauty-even.trycloudflare.com/ 的侧栏、日期导航、主任务突出、时段安排、表单层级与撤销操作；保留 Reva 本人认证、显式保存及 CAS。

## 本批行为与验收

1. 宽屏固定于工作区的左侧分区导航，窄屏可折叠导航；Logo 首页链接、当前视图标题、保存状态始终可达。
2. 上/下一周、回到今天、周一至周日切换；跨周保留未保存草稿，不擅自创建空周或写 API。
3. 今日重点显示真实主任务、明确完成项数；任务编辑保留已有字段、主辅数量约束。四时段时间安排由同一任务数组派生，点击可定位编辑，未分配时为空态。
4. 快捷锚点在今日任务、时间安排和日记录之间跳转；桌面/窄屏不遮挡表单与保存操作。
5. 撤销/重做只作用于当前账号的未保存工作区草稿；有界内存历史；编辑后新分支清除 redo；保存、重新读取、导入恢复成功后清空历史；切换账号销毁历史；忙碌时禁止撤销；计时启动/结束仍显式保存且不改变任务完成事实。
6. 保持现有周主线、四时段七天表、周复盘草稿/归档、季度、机会、备份完整入口；不更改 API 或数据格式。已有错误、409 草稿保留、账户 epoch 不退化。

## 范围边界与后续真实缺口

本批是既有核心流程的体验对齐，不宣称原版十二页完整复刻。晨听/此刻多媒体、一生八章文档与人生周历、年度矩阵、结构化事件/错误/习惯、跨期趋势需要单独扩展数据及双端备份契约；不把个人原站预填内容、默认健康数值、参考服务“已保存本机”声明复制进 Reva。不增加外发、TTS 云服务、健康重复录入或自动保存。

## 实施与验证

仅修改 Web LifeNavigationWorkspace、相关视图组件、model 与 CSS/测试。保持 main 及其他会话工作。先新增可失败的日期/任务同源/撤销保存与账号隔离回归，然后实现；运行对应 Vitest、tsc、ESLint、System Map、Dossier 检查及合成账号浏览器桌面/窄屏验证。独立 reviewer 验证保存/历史/隐私不变量。没有部署授权扩展或发布回执时仅报告本地状态。
