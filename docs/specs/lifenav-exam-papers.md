10/27—11/8 用2024卷摸底与复测；11/9—11/29 用2025卷强化；11/30后用2026卷检测。每轮9个分段，日期稳定、跨设备一致；重复轮次明确标为复测，不声称每天无限新题。日期安排不代表实际完成或能力诊断。完整3小时模拟需另行腾出时间，分段分数不能冒充整卷成绩。

每日记录：年份、科目、题号、正确数、实际耗时、错因与复测日期。客观题已实现逐题录入和错题调度；写作与翻译仍需人工批改，不进入自动判分的 300 题统计。后续自适应分配只能基于真实作答数据，而不是勾选完成推断掌握。

## 练习保存与新题修复（待本轮发布）

用户实际反馈：练习区仍是固定旧题，提交后刷新丢失。本轮修复该区本身：提交按钮经当前账号与 expected_revision 保存整个当前工作区，旁边明确标注会同时保存其他草稿。只有成功回执才显示“作答已保存”；网络/版本冲突保留本地答案、阻止继续下一题并提供重试。首次与最近一次复练保持既有记录语义；不会伪造学习成绩。原有手动计划/笔记保存方式保留。

新增原创专项题库与日期稳定的未做题优先队列；不把原创题冒充历年真题，也不把日期轮换当成无限题库生成。全部题库包含已做题，界面显示上次作答日期和状态。题库耗尽会明确说明。既有20题ID及纸上真题日程保持兼容。

验收覆盖：无额外保存点击即调用账号隔离保存；重载保留记录；失败不冒充成功、可重试；重复点击只有一次写入；换账号不接受旧请求结果；Web/Mobile一致；既有每周100项任务上限保留并明确报错。

### Web 栏目链接

LifeNav 在现有 `/agenda?navigation=week` 路由上用 `tab` 标识栏目：
`today`、`week`、`exam`、`focus`、`notes`、`review`、`achievements`、`direction`、`opportunities`、`backup`。
备考子栏目用 `study=plan|practice|resources`。例如
`/agenda?navigation=week&tab=exam&study=practice` 直接进入练习与错题。
点击栏目添加浏览器历史记录，刷新、复制链接及前进后退恢复对应栏目。
未知值回到默认栏目；保留其他查询参数与锚点。切换栏目不会保存、重载或清空工作区草稿，
离开 LifeNav 的原有未保存提醒继续有效。URL 不携带账号、答案或私有学习内容；接收链接的人仍读取自己的账号数据。

### 专项练习回看（2026-10-27）

Web 增加上一题、答题历史与错题本。上一题优先回到本次浏览轨迹，已答题不因
移出未做队列而无法查看。历史读取服务端返回的 workspace.data，不能将尚未保存的
draft 当作历史；仅查看不写入答案，主动重新作答仍沿用 revision/CAS 保存。

展示每日首次答案和最近复练结果。待复练表示最近作答未通过；错题本保留这两类
已存记录中可证明答错的题，包括复练已答对的题。不是完整尝试日志，旧版被覆盖的
中间尝试无法恢复。本次不改变存储格式，Web 回看交互与 Native 分别发布。

### 手机端历史回看（2026-10-27）
