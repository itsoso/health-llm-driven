# 从人健康迁移到宠物健康：切入方案

> 战略草案 · 2026-05-29 · 假设前提：**中国优先 / 混合 C+B / 猫狗为主**
> 数据来源见文末「参考来源」。本文是决策草案，非已定计划。

---

## 一、结论先行（TL;DR）

**不要从硬件或纯远程问诊切入，从「AI 分诊 + 结构化健康档案」的 C 端微信小程序切入，用结构化档案这把钥匙撬动 B 端（保险核保/理赔 + 兽医复诊决策支持）。**

核心逻辑链：本平台最值钱的不是「健康建议」，而是**可解释、可追溯、带结果闭环的多 Agent 架构**。宠物赛道有两个尚未被解决的真实痛点恰好需要这套东西：

1. **C 端痛点**：「这到底是不是急症？要不要花几百块跑一趟医院？」——西方已被 DogMD/TTcare 验证，中国严重欠供给。
2. **B 端痛点**：宠物保险「投保易、理赔难」，渗透率仅 1.2–3%（欧美 30%+），核心卡点是**缺乏标准化、可信、纵向的健康数据**做核保和反欺诈。

现有 `orchestrator + arbitration + audit + evidence` 架构几乎是为 B 端「可解释裁决 + 证据链」量身打造的。**C 端是数据采集前端，B 端是变现后端，Pet Twin（宠物数字孪生）是双边飞轮的共享对象。**

## 二、市场判断：为什么是现在，钱在哪里

| 维度 | 数据 | 含义 |
|---|---|---|
| 城镇犬猫消费 | 2025 年 **¥3,126 亿**（犬 1606 / 猫 1520），白皮书称已破 3100 亿大关 | 大盘足够，且猫增速(5.2%)>犬(3.2%)，猫是更快的细分 |
| **宠物医疗** | 2024 年 **¥940 亿，+14.5%**，2025 预计 ¥1,087 亿，占总消费 **28%**（仅次于食品 52.8%） | 医疗是第二大且高增长池子，保健品增速 >30% |
| **宠物保险** | 2025 保费约 **¥30 亿，+76%**，连续 5 年翻倍；但渗透率 **仅 1.2–3%**，1.26 亿城镇宠物对应 <400 万投保，**97% 空白** | 蓝海中的蓝海；痛点明确 ＝「理赔难」＋缺数据 |
| 人群 | 养宠主力 **90/95 后 >60%，本科以上 75%** | 年轻、高学历、数字原生、愿为宠物溢价付费——和现有产品用户画像高度同构 |

**关键 timing**：保险在爆发拐点但被「缺可信数据」卡住，谁能提供 vet-grade 结构化档案，谁就握住核保方的命门。

## 三、宠物健康 ≠ 人类健康：四个结构性差异（决定产品重做哪些）

1. **病患不能自述** → 必须靠「主人观察 + 行为 + 照片/视频 + 可穿戴 + 化验单」推断。关键词意图分类**直接报废**（本来也该升级），改成观察驱动 + 视觉驱动。
2. **品种 = 新的「基因面板」** → 髋关节发育不良、短头颅呼吸综合征、品种遗传病。人类 SNP specialist（MTHFR/APOE）概念迁移成**品种易感模型**。
3. **数据源完全不同** → 没有 Apple Watch 级普及的可穿戴；小佩/Fi/PetPace 项圈尚处早期，有佩戴不适、误报、不替代诊断等硬伤。**不能押注硬件采集**，靠主人日志 + 照片 + 化验单 OCR + 品种先验冷启动。
4. **视觉是主模态** → 皮肤、眼睛、牙齿、步态、呕吐物、粪便照片分诊。已有 `LLM_VISION_MODEL` 和医检 OCR——**这块几乎零迁移成本**。

## 五、切入方案：楔子 + 飞轮（含为什么不选别的）

**被否决的路径：**
- ❌ **硬件先行（智能项圈）**：小佩（2013 年成立，2022 营收破 10 亿，估值 30 亿+，1000+ 门店）、霍曼已占位，重资产、非所长。
- ⚠️ **纯远程问诊平台**：监管在收紧（见第八节），需自建兽医网络，同质化严重。

**推荐楔子（按顺序）：**

```
C 端微信小程序                         B 端变现（飞轮后端）
┌─────────────────────────┐          ┌──────────────────────────┐
│ ① AI 分诊（急症分级）       │  数据    │ ④ 保险：结构化档案 → 核保    │
│ ② 化验单/体检拍照解读       │ ───────▶ │    数据 + 理赔证据链反欺诈    │
│ ③ Pet Twin 纵向健康档案     │  Pet     │ ⑤ 兽医：可解释复诊决策支持    │
│   + 结果闭环 + 中毒急救     │  Twin    │    portal（省时分诊导流）     │
└─────────────────────────┘          └──────────────────────────┘
        ↑ 最低 CAC，优先复用现有栈            ↑ 高客单、强留存、可解释＝壁垒
```

**为什么这个组合赢**：轻资产、优先复用现有架构、踩中两大真实痛点、结构化档案是双边共享对象、**可解释裁决是对 B 端（保险+兽医）的独家卖点**——一个 GPT 套壳分诊器做不出 `arbitration + audit + evidence_refs`。

---

## 六、商业模式（C+B 混合）

- **C 端**：分诊免费引流 → 订阅（深度档案/无限解读/养护计划）+ 电商/保健品分成。但 C 端订阅天花板低，**主要作用是采集数据 + 摊薄 CAC**。
- **B 端（真正的钱）**：
  - **保险**：向众安/平安/支付宝宠物医保提供 ① 核保数据（纵向健康档案降低逆选择）② 理赔证据链（结构化病史 + AI 裁决 → 直击「理赔难」与欺诈）。变现：数据/SaaS 费 + 分销分成。**保险方还能反向补贴 C 端获客。**
  - **兽医/宠物医院**：可解释复诊决策支持 + 分诊导流到院。定位「省时 + 导流」而非「取代兽医」，化解抵触。

| 阶段 | 时间 | 做什么 | 验证指标 |
|---|---|---|---|
| **Phase 0 验证** | 0–3 月 | 微信小程序 MVP：品种档案 + **AI 分诊（急症分级）** + **化验单拍照解读** + 中毒急救规则。最大化复用现栈 | 分诊准确率（兽医复核）、留存、付费意愿信号 |

| **Phase 2 B 端飞轮** | 9–18 月 | 兽医端可解释复诊 portal + 保险理赔证据链 SaaS | B 端客单、双边留存、数据网络效应 |

## 八、风险与护城河

**监管（最关键）**：目前国家**未对互联网宠物医疗设专门准入**，有《动物诊疗许可证》的机构即可开展；但人员资质、诊疗范围均未限定，处于「野蛮成长」，2023《动物防疫法》+《动物诊疗机构管理办法》已建分级管理，**趋势是收紧**。
→ **应对**：定位「AI 分诊 + 兽医在环」，**不碰处方/确诊红线**；urgency 分级保守 + 强制「建议就医」免责；为即将到来的严监管预留兽医审核接口。

| 风险 | 应对 |
|---|---|
| 误诊致宠物伤害的责任 | 分级保守、不替代兽医、强免责、关键告警强制导诊 |
| 冷启动无自述/无普及可穿戴 | 靠主人日志 + 照片 + 化验单 OCR + 品种先验，**不依赖硬件** |
| 知识语料/安全规则重建成本 | 与 1–2 家宠物医院/兽医 KOL 合作做语料标注（**同时是获客与背书**） |
| 兽医 B 端抵触 | 定位「省时分诊 + 导流到院」 |

**护城河**：不是分诊本身（会被抄），而是 **`结果闭环 hit-rate × 可解释裁决 × 纵向 Pet Twin × 保险数据网络效应`**——竞品要补的是已经做完的那部分。

---

## 九、最便宜的下一步（先验证再投入）

1. **2 周内**：用现栈快速改一个微信小程序分诊 demo（Pet Twin 用最小分区 + 化验单 OCR 复用 + 中毒规则），投放给 3–5 个宠物社群。
2. **测三件事**：分诊准确率（找 1 位兽医盲审）、7 日留存、「愿付费/愿买保险」信号。
3. **并行**：约 1 家保险（众安宠物险）+ 1 家连锁宠物医院聊「结构化档案数据合作」意向——B 端有无兴趣，决定这个方案成不成立。

---

**一句话**：人健康练出来的「可问责 AI」是最稀缺的资产；宠物赛道里，**保险的「缺数据」和宠主的「不知是否急症」恰好都是问责性问题**。从 C 端分诊采数据、用 B 端保险/兽医变现，是把架构优势直接换成钱的最短路径。
