# Agent 批量健康记录删除实施计划

1. 用失败测试锁定闭合批量语法、目标编译、owner 全集校验和确定性删除计划。
2. 扩展饮食删除授权证据为去重、最多 5 个 ID，同时保持所有类型的单条兼容和危险表达 fail closed。
3. 在 owner lookup 后一次性解析全部目标；不完整时零写入，完整时由服务端生成全部删除调用。
4. 运行聚焦回归、LLM 变更闸、Dossier/System Map/静态检查。
5. 本地提交后做独立 G4 安全评审；GO 后推送 main、执行 Backend 发布和生产只读验证。

回滚点是发布前生产 SHA；无 schema、API 或 Mobile 资产变更。
