# AIGC 短视频规格与生成体验实施计划

## 范围

本轮只完善 HappyHorse 单任务 3–15 秒链路。16 秒以上作为后续父子任务合成能力，不在本轮伪造支持。

## 不变量

- 所有外部生成必须由登录用户点击一次性确认卡。
- prompt、模型、源图片由服务端绑定，客户端不能提交或替换。
- 最终规格参与幂等指纹；重复点击不产生第二个 provider 任务。
- provider 结果继续复制到用户私有存储后才展示。
- 日志和运维指标不包含 prompt、图片 URL 或健康正文。

## 实施

1. 后端：模型能力注册表；确认时长白名单；任务规格和结果元数据投影。
2. Mobile：5/10/15 秒分段选择；展示 720P、比例和阶段；轮询退避。
3. 运维：按类型聚合、生成时延 P50/P95、输出体积。
4. 验证：provider、确认幂等、API、运维、卡片 Jest、TypeScript。
5. 发布：后端先部署，随后 production OTA，最后真机确认。

## 后续

16–30 秒需要父任务、分镜子任务、冻结脚本、部分失败恢复、FFmpeg 合成、音频归一化和统一成本披露，单独立项。
