# AIGC 视频时长选项设计

## 目标

小巴短视频确认卡统一提供 `5 秒`、`8 秒`、`15 秒`三个真实可执行选项。新草稿由后端下发同一能力契约；历史草稿缺少 `duration_options` 时，Mobile 使用相同回退值。

## 决策

- HappyHorse 单任务继续遵守原生 `3–15 秒`范围，不伪造 16 秒能力。
- 将产品选择集从 `5/10/15` 调整为 `5/8/15`。
- 后端能力注册表是权威来源，确认投影和 Agent 卡片继续从该注册表生成。
- Mobile 仅保留兼容旧卡所需的 `5/8/15` 回退，不放宽服务端校验。
- 用户选择 8 秒或 15 秒后，该时长进入确认请求、任务指纹、Provider 请求与任务规格回执。

## 错误与兼容

- 非整数、低于 3 秒或高于 15 秒的请求继续由 API 和服务层拒绝。
- 历史卡中原选择为 10 秒时，Mobile 将默认选择回落到 5 秒，避免显示一个不再提供的幽灵选项。
- 已经提交的 10 秒任务保持可读取和播放，不修改历史任务数据。

## 验证

- Backend：能力注册表返回 `5/8/15`，8 秒确认可完整下传，16 秒仍被拒绝。
- Mobile：新卡和缺少选项的历史卡都显示 `5/8/15`；选择 8 秒后提交 `{ duration_seconds: 8 }`。
- 回归：AIGC 后端定向测试、Mobile 卡片测试、TypeScript、lint、文档漂移检查。
