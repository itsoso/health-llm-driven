# 2026-06-29 Chat / 首页阿衡人格文案收敛计划

> 目标:把 Mobile 主动健康主路径里仍残留的“健康 Agent”收敛为“阿衡”,让首页、Chat、模型选择、分享文本和无障碍标签与本周发布命名一致。

## 背景

- 本周发布目标已确定 App / 主名 / AI 人格三位一体为 `阿衡`。
- 前序切片已覆盖 App Store 元数据、首页部分入口、快速记录和 Chat 动态卡片安全边界。
- Chat 主页面、分享文本工具层、菜单分享卡和首页主卡仍有旧称残留,会让用户在最核心动线里看到不一致的人格命名。

## 实施

- Chat 模型选择器标题统一为 `阿衡`。
- Chat 空态提示和 starter chip 无障碍标签统一为 `阿衡`。
- Chat 单条回复分享标题、分享尾注、对话节选标题和尾注统一为 `阿衡`。
- 菜单分享卡的分享尾注统一为 `阿衡`,并导出纯文本构建 helper 方便回归测试。
- 首页 `HomeCommandCard` 顶部人格和“问原因”无障碍标签统一为 `阿衡`。
- 底部 Chat tab 无障碍标签后续继续收敛为 `阿衡,与健康参谋对话`。

## 验收

- Chat 页面测试能看到 `阿衡`,且空态文案为 `阿衡 · 会带上你的健康上下文`。
- 模型选择器测试确认不再展示 `健康 Agent`。
- Chat 单条回复分享标题为 `阿衡 · 建议`,分享正文尾注为 `— 阿衡`。
- 菜单分享卡尾注为 `— 阿衡`。
- 选中对话分享使用 `【阿衡】` 和 `— 阿衡对话节选`。
- 首页主卡展示 `阿衡`,并提供 `问阿衡原因` 的无障碍标签。

## 状态

- 当前状态:已实现并通过本地聚焦测试。
