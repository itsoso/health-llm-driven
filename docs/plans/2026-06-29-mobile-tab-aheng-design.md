# Mobile Tab Naming Design: 今日 / 阿衡 / 记录 / 我

## Decision

底部导航采用 `今日 / 阿衡 / 记录 / 我`。

## Rationale

- `私教` 偏健身训练,无法覆盖体检报告、用药、补剂、睡眠、HealthKit 和 7 天健康运行时。
- `参谋` 是正确定位,但作为 tab label 偏抽象,不如直接用用户要找的 AI 人格 `阿衡`。
- `阿衡` 与 App 名、AI 人格、Chat + 动态 UI 卡片入口三位一体,短、清楚、可长期品牌化。

## UX Contract

- `今日`:每日状态、最重要行动、时间线。
- `阿衡`:Chat、动态 UI 卡片、健康参谋对话。
- `记录`:饮食、喝水、运动、体检、症状等低摩擦录入。
- `我`:档案、数据来源、隐私、账号、设置。

## Copy Rules

- 底部 tab 不再使用 `私教`。
- App Store 高可见文案使用 `今日 / 阿衡 / 记录 / 我`。
- `健康参谋` 保留为定位词,用于描述阿衡的角色,不作为底部 tab label。
- 技术路由仍保留 `/chat` 和 `chat.tsx`,不做技术符号重命名。
