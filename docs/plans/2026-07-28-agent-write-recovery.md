# Agent 写入失败恢复实施计划

> 实施状态：步骤 1-7 已完成；生产健康已验证，剩余一次真机可重试失败恢复闭环作为终端验收。

1. 以单元测试锁定窄确认短语、owner scope、会话顺序和写入检查点屏障。
2. 新增内容最小化的 `retry_source_turn` 恢复动作和解析器。
3. AgentExecutor 将“展示消息”和“执行消息”分离，并在同一 client turn 恢复时
   从用户消息元数据重建绑定。
4. 恢复原图片给视觉/饮食链路，同时把当前回合作为新的写入检查点来源。
5. 在助手终态和 SSE `done` 中返回恢复动作；成功、确认中或不确定写入不生成。
6. 执行 focused 回归、饮食图片回归、Runtime 回归和安全评审。
7. Gate 全绿后提交、推送、部署，并验证生产健康状态。
