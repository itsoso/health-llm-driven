# 饮食修正与聚餐份额 PRD

用户希望编辑食物后热量与营养同步更新，并能对全桌照片声明“我只吃了 1/5”。入口为现有聊天卡片与饮食编辑，不增加操作层级。

权威需求：Personal Health OS PRD R5/R10/R11。行为、接口、安全边界与验收单一真源见 [feature spec](../specs/active/2026-09-21-diet-edit-shared-portion.md)。

优先让用户改食物描述和个人份额，而非要求手工算五项营养。明确估算与保存的先后，避免展示旧数值如同已重算。份额表示整桌的绝对占比，不等于人数平均分配；不均匀吃菜需要改各菜量。无待用户裁决的范围分叉。
