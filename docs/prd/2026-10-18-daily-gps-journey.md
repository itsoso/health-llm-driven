# 主动开启的每日行程

用户原话：“能否实时获取我的gps信息 记录和分析我一天的行程？”随后确认“按你说的来”。

目标：用户一天只需主动开启一次，结束后能看到真实采集的路线、停留、移动时间及缺失区间，帮助复盘出行占用的时间。对应主 PRD R9 结果复盘、R10 Mobile 主体验、R12 数据缺失不可伪完成、R15 无额外推送、R17 行为上下文。GPS 不直接推断健康结果。

首版包括主动开启、系统后台授权、当天截止、省电采样、暂停/恢复/结束、1/7 天保留、本人私有复盘、修正与删除。不开自动每日重启；不分享位置，不进行医疗或因果判断。详细状态/API/安全合同见 ../specs/2026-10-18-daily-gps-journey.md。

用户已授权上述方案实现；每次真实采集仍需 App 内主动开启及系统权限。iOS 调度、信号和强退可能中断，不承诺逐秒连续。交付是后端及新的原生包，不以 OTA 或模拟坐标代替硬件验收。
