# Enter 键 / 杠杆点战略论纲（2026-06-16）

> **这是策略层,不是产品路线图。** 产品方向的唯一权威仍是
> [`reva-personal-health-os-prd.md`](reva-personal-health-os-prd.md) —— 本文不 fork 它,
> 只回答一个更上游的问题:**在「大模型时代个人健康管理」里,真正的杠杆点是什么,
> 我们现在的代码站在杠杆的哪一段。** 锚点用户(创始人本人)是 PMF 原型,本文的判断
> 来自其 2026-06-16 的一次合并思考 + 对当前仓库的逐模块核对。

---

## 0. 一句话

> 个人健康管理的 Enter 键 =
> **一个拥有你生活写入权的 AI,每天替你执行少数它「挣到了 CI 置信」的微决策、
> 把其余的压成一键提议,并每季度用复测数据告诉你「这些决策对你是否真有效」,
> 在置信区间收敛后才扩展它的权限边界。**

---

## 1. 主要矛盾

**感知精度在指数级增长 ⇄ 干预执行仍依赖人类意志力的线性输出。**

- 设备/模型让「测得越来越准」几乎免费(Apple/华为/Garmin/Whoop 已把内环吃掉);
- 但「测准 ≠ 做到」。锚点用户本人就是最有力的反例:**24 种补剂、12.6% 依从率、
  胃溃疡** —— 一个愿意花钱、有数据素养、强动机的重度用户都做不到,普通用户更不可能。
  这证明**「看板/Read 范式」已经触顶**:再多一块表盘、再准一个 HRV,都不解决执行。

**解法 = 把执行环节从人类意志力迁移到 Agent 写入权 —— 但前提是建立个体化效应的
可验证收敛机制。** 矛盾不在数据感知,在执行迁移。

---

## 2. 公式:三者缺一不可

```
Enter键 = Write权限 × 个体化先验 × 闭环验证
            │            │            │
   缺它→看板产品   缺它→通用大模型   缺它→规模化伤害
   (当前所有玩家)    (GPT 也做不了)    (自动驾驶撞墙)
```

- **只有 Write,没有验证** → 错误指令 × 自动执行 = 系统性伤害规模化。
  (反例:若当时有 Write 权限自动给锚点用户加 NAC+姜黄素+槲皮素+鱼油,全是空腹刺激
  胃黏膜的,结局更糟 —— 见 [`memory/project_founder_gastric_biopsy_hp_negative`]。)
- **只有验证,没有 Write** → 还是看板。
- **只有先验,没有闭环** → 通用大模型,给不出「**对你**」的答案。

---

## 3. 三层嵌套飞轮

| 环 | 周期 | 链路 | 谁能做 |
|---|---|---|---|
| 内环 | 每日 | Agent 写入 → HRV/睡眠/血糖短反馈 → 信任增加 | Apple/华为 |
| 中环 | 每月 | 行为累积 → 体重/血压/压力变化 → Write 权限扩展 | Garmin/Whoop |
| **外环** | **每季** | 干预策略 → HbA1c/ALT/血脂复测 → **CI 收敛** → 权限扩展 + A2A 接入 | **只有我们** |

**护城河 = 外环,且更精确是 per-user 纵向因果账本。** 两年后系统知道「**对你**:NAC 抬了
ALT、镁修了睡眠、这条协议黏住了那条没有」——这是 **时间 × 你** 的乘积,Apple 买不到,
对手每个新用户从零起。**因此增长指标是「单用户验证过的闭环轮次」,不是用户数。**

### 两个收尾洞察(决定节奏)
1. **冷启动:先验积累必须先于 Write。** 外环一圈 = 一个季度,新用户零先验、零闭环史 →
   Agent 几个月内都不该自治写。**飞轮的启动器不是 Write,是把「复测召回 + 零摩擦打点」
   做到极致这台先验积累机** —— 先转几个季度,Write 才配上场。
2. **Write 自治被外环结构性封顶 → 终态是分级信任,不是「每天 100 个自治决策」。**
   验证是季度级的,所以**大多数动作永远停在一键提议**,只有 CI 证明对你有效的少数升级到
   自治。**安全带(safety-gate / Safety Guardian)不是补丁,是 Write 自治的速度上限。**

## 6. 创业切入点(给融资/定位)

**不是高净值人群(那是「管家」需求,不是「健康」需求)。** PMF = **慢病早期 + 多指标异常
+ 有数据素养的中产 35–55 岁男性**(即锚点用户本人):不缺钱缺时间、已买一堆设备和补剂、
指标在缓慢恶化但没到住院、最痛的是「知道有问题但不知道下一步」。中国此人群 ≥ 3000 万。

> **N=1 的纪律风险**:为单一用户(自己)建产品 = 当下正确(单租户 + dogfooding),但要警惕
> 把一个人的生理过拟合进全局(如血氧全局硬剔 Garmin、HP- 胃溃疡路由)。**个体先验必须
> per-user**,凡是写死成全局规则的地方都是过拟合气味,留多租户 TODO。

---

## 7. 一句话收束

- 主要矛盾不在数据感知,**在执行迁移**。
- 指数增长不在用户规模,**在验证过的闭环轮次**。
- 护城河不在算法智能,**在 per-user 因果账本的复测收敛**。
- 切入点不在高净值,**在中产慢病早期男性**。
