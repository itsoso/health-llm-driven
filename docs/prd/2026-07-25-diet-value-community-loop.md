# 饮食价值回执与同行支持 PRD

## 目标

饮食记录成功后的第一屏就回答三个问题：

1. 记录是否真实保存；
2. 今天下一步做什么；
3. 距离自己的减脂目标还有多少。

用户可以选择把经过隐私裁剪的饮食执行事件发到匿名同行圈，获得支持，而不是进入体重或热量竞争。

## 用户流

```text
拍照/语音/文字记餐
  -> 幂等写入 DietRecord
  -> RecordQualityCard
       -> 今日营养进度
       -> 目标距离与 7 日观测变化
       -> 单一下一步动作
       -> 私密（默认）
            -> 用户确认发布
            -> 匿名同行动态
            -> 支持 / 同路 / 学到了
```

## 产品原则

1. 目标距离来自真实体重和目标，不由模型生成。
2. 单餐只影响当天饮食结构，不宣称直接导致体重变化。
3. 体重过期、目标缺失或目标不安全时诚实降级。
4. 发布必须由用户主动触发，社区不读取病史、用药或位置。
5. 激励服务于可执行行动，不服务于停留时长、连续天数或排行榜。

## 核心体验

### 私人价值回执

- 标题：`午餐已记录`
- 记录摘要：本餐食物与宏量营养
- 今日进度：已记录餐数、蛋白进度
- 目标进度：当前、目标、剩余、7 日变化、数据日期
- 下一步：一个确定动作
- 操作：调整记录、看下一餐建议、发到同行圈

### 同行圈

- 匿名显示为“同行者”
- 卡片只展示餐次、食物摘要、热量/蛋白和可选文字
- 三种支持反应，不显示用户排行榜
- 可删除自己的发布，可举报不当内容

## 成功指标

- 饮食写入后价值回执展示成功率；
- “下一步动作”后续完成率；
- 有有效目标和体重数据用户的目标进度可用率；
- 主动发布成功率和支持反应率；
- 社区关闭率、举报率和误暴露率；
- 不以 DAU、停留时长或点赞总量作为北极星。

## 非目标

- 评论、私信、关注关系；
- 公开昵称或头像；
- 自动发布；
- 原始餐食照片公开；
- 减重排行榜、断食挑战、热量赤字挑战；
- 预测精确达标日期。
