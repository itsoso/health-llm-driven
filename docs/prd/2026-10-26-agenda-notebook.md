# 人生导航记事本

在现有私人规划工作区增加记事本入口，服务于规划观察和反思。用户手动新建、编辑、搜索、删除纯文本笔记并保存工作区。笔记跨周保留，保存后可重新读取；沿用工作区撤销/重做、离页提醒与版本冲突。

最多 100 条，标题 200 字符、正文 20000 字符，沿用整个工作区 256 KiB 上限。仅当前认证本人访问；不自动提取健康事实、触发提醒或交给 AI。空标题允许显示“无标题笔记”。删除前确认，保存前可撤销。

验收：保存后重开保留；失败保留草稿且不显示成功；切账号清除本地草稿；HTML 作为纯文本；旧客户端省略新字段时不能擦除现有笔记。完整 UI 在 Web，移动端仅保持数据契约兼容。
