# Build 48 — A 到 I 完整产品改进

## 给 TestFlight 用户看的 What's New

### 🎙️ 新增四种语音对话场景
所有都用「私享女声」(声音复刻) 主动开口，可以接话:

- **早 7:30 — 晨间简报**: 手机推送一条简报「早安。睡了 7 小时 30 分，电量偏低，今天恢复为主」，点开私享女声播报 + 回话规划。
- **周日 20:00 — 周聊**: 私享女声回顾本周「跑了 1 次共 3 公里，HRV 改善 6ms…下周想怎么安排?」
- **跑前准备**: 记录页面点「跑前准备」，AI 根据当日恢复度直接给目标心率 + 时长建议。
- **声音笔记**: 记录页面点「声音笔记」，对着说「今天头疼吃了布洛芬」，AI 自动归类录入。

### 🤖 AI 主动找你聊
血氧 / HRV / 睡眠 / 心率告警时，AI 不再只发一条字，而是主动开口:
> "嗨，我注意到你最近血氧偏低，是不是侧睡或枕头比平时高?"

你的回答会被永久记住，下次同类告警 AI 会带着上下文。

### ⚙️ 告警反应方式 (设置 → 推送通知)
新增三档:
- **静默** — 只写到告警列表
- **提示** — 推送 + 跳详情页
- **对话** — 推送 + AI 主动开口（默认，最聪明）

### 🏃 跑后教练播报 (运动详情页)
跑步详情页 AI 分析卡片旁多了「听一下」按钮，私享女声 60-100 字播报本次跑步评价 + 下次建议。

### 👨‍👩‍👧 家庭健康 (设置 → 家庭健康)
看家人的健康概况（睡眠 / 心率 / 步数 / 告警），只读 MVP.

### 📅 健康事件流 (设置 → 健康事件流)
30 天的运动 / 告警 / 用药 / 体检统一时间线，每条可点开详情。

### 💊 用药管理 (设置 → 用药管理)
增加 / 停用药物，5 秒内可撤销，已停用列表可恢复（防误点击）。

### 🛠️ Bug 修复
- 语音对话音量小（贴脸路由问题）
- 段落开头还在念，下一段就提前开始（TTS 重叠）
- 关闭按钮无法停止 TTS
- 体重记录 5 次"操作未成功" — 现在 AI 会先确认再记
- 录音「停 1.2 秒」自动发送，不用再手动点
