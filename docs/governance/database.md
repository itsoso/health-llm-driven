# 数据库治理

## 权威语义

PostgreSQL 是生产环境和所有新数据库行为的唯一语义真源。SQLite 只用于快速单测与迁移兼容反馈，不能证明 PostgreSQL 的约束、锁、并发、JSONB、时区、索引或方言行为。

## Schema 与迁移

- 新表、字段、约束、索引或类型变化必须通过受管迁移完成；禁止只改 ORM 或在线库。
- 迁移要可重复、可观察，并说明向前兼容、回滚/前滚策略和大表风险。
- API、ORM、后台任务和客户端类型受契约影响时同批更新与验证。
- JSON 优先使用 PostgreSQL `JSONB`；时间使用带时区语义；默认值与约束由数据库和应用边界共同验证。
- 用户健康数据查询必须带认证用户/租户隔离；批处理和管理员路径也不例外。

## 完成证据

至少包括：迁移静态检查、PostgreSQL 集成验证、关键约束正反例、受影响查询计划/索引证据，以及部署顺序和回退条件。SQLite 通过只能算快速反馈，不能关闭数据库 Gate。
