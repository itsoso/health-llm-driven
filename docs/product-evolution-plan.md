---

## 0. 产品一句话

**一个专为 35-55 岁男性打造的「会主动出手、能验证效果」的 AI 健康管家:用难言之隐(ED/脱发/精力)隐私入口拉新,用代谢健康闭环(脂肪肝/三高)沉淀终身价值,用直播私域低成本变现。**

与现有 HealthPilot 的关系:**不是新建,是聚焦** —— 把已落地的 AI OS(Twin + 11 专家 + 51 规则 + N-of-1 闭环 + 多端)收敛到「中年男性」这一个高价值人群和「ED 引流 / 代谢沉淀」这一条主线上。

---

## 1. 目标用户与设计原则

### 目标用户画像
- 35-55 岁男性,一二线城市,年收入中高
- 体检有异常(脂肪肝/血脂/血压)但拖延就医(就医延迟率 38.1%)
- 有难言之隐(ED/脱发/精力下降),羞于线下、价格不敏感
- 不爱戴东西、不爱啰嗦、不爱被打扰

### 五条产品设计原则(从画像直接推导)
1. **隐私优先**:难言之隐话题端到端隐私 + 隐名配送(对应隐私 Tier 分级)
2. **默认沉默,异常才出手**:中年男性偏「连续后台采集 + 关键时刻提醒」,不要日报轰炸
3. **无感采集**:硬件零佩戴负担(戒指/床垫),数据自动流入,不要手动录入
4. **结果可见**:每个干预给「N 周前 vs 现在」指标对比卡——这是信任和续费的核心
5. **服务即销售**:AI 建议天然带出检测/补剂/问诊履约,绕开纯订阅 1.7% 转化死局

## 2. 产品形态:三层结构

```
┌─────────────────────────────────────────────────────────┐
│  入口层 (拉新)  ── 难言之隐隐私问诊 + 直播私域           │
│  ED / 脱发 / 精力:轻问诊 → 个性化方案 → 隐名配送        │
└───────────────────────────┬─────────────────────────────┘
                            │ 免费体检解读为钩子,导入↓
┌───────────────────────────▼─────────────────────────────┐
│  核心层 (留存/护城河)  ── 代谢健康闭环                   │
│  Pet... 不,Health Twin 建档 → MetabolicSpecialist 分析  │
│  → Agent 主动出手(三档)→ 12周 N-of-1 → 指标对比卡      │
└───────────────────────────┬─────────────────────────────┘
                            │ 数据越深越走不掉
┌───────────────────────────▼─────────────────────────────┐
│  数据层 (无感采集)  ── 贴牌硬件 + 体检 + 手动兜底         │
│  无订阅戒指(HRV/睡眠/血氧)+ 床垫(呼吸/OSA)            │
│  + CGM 短探针(代谢深挖期)+ 体检报告 OCR                │
└─────────────────────────────────────────────────────────┘
```

**变现贯穿三层**:入口层卖问诊+药/补剂、核心层卖会员+检测复购、数据层卖/贴牌硬件 —— 全部走创始人最懂的直播+私域+电商履约。

## 3. 用户旅程(端到端闭环)

```
直播/私域看到内容("40岁男人精力下降的真相")
   ↓ 隐私问诊(ED/脱发/精力)—— 低门槛、高隐秘、价格不敏感
首单履约(补剂/药/检测盒)+ 免费体检报告 AI 解读  ← 现金牛 + 建 Twin 钩子
   ↓ "你的肝酶/血脂偏高,我帮你做个 12 周改善计划"
Health Twin 建档(体检 + 戒指 + 可选 CGM)
   ↓ Agent 主动出手:监测异常 → 干预提案(51规则安全闸)→ N-of-1 实验
12 周后:指标对比卡("肝酶 ↓28%,血脂回正")  ← 信任时刻 / 续费触发 / 路演弹药
   ↓ 复购检测 + 补剂 + 升级会员 + 复盘下一轮
终身代谢健康管理(高 LTV,数据沉淀,走不掉)
```

**关键转化点**:① 难言之隐 → 首单(已验证高转化);② 首单 → 代谢建档(免费体检解读做钩子);③ 12周 outcome → 续费(指标对比卡)。每个点都要单独埋点测转化。

## 4. 功能演进路线(基于现有代码资产)

> 标注:✅ 已有可复用 / 🔧 需改造 / 🆕 新建

### MVP(0-3 月):跑通一条代谢闭环 + 一个难言之隐入口
- 🔧 **聚焦版首页**:从通用健康改为「今日身体状态 + 该做的 3 件事」,中年男性视角(复用 `mobile/app/(tabs)/index.tsx`)
- 🆕 **隐私问诊入口**:ED/脱发/精力 轻问诊流(隐私 Tier + 隐名)→ 接 OpenClaw skill 履约
- ✅ **体检报告 AI 解读**:已有 `upload_medical_exam_text` + exam-explain → 作为建 Twin 钩子
- ✅ **代谢闭环**:`MetabolicSpecialist` + `episodes.py` + `personal_outcome.py` 已就位 → 串成「体检→分析→12周 Episode→对比卡」
- 🆕 **指标对比卡**:N 周前 vs 现在(肝酶/血脂/CGM TIR)—— 信任时刻的 UI
- 🎯 目标:3 个种子用户跑完整闭环 + 真实 outcome 数据(估值杠杆①)

### Phase 2(3-9 月):Agent 主动化 + 硬件接入 + 直播变现
- 🔧 **Agent 主动出手三档**(对应 RFC 方向三 + 五):监测触发(复用 Celery)→ 干预提案(51规则安全闸)→ N-of-1 自动验证
- 🆕 **贴牌硬件接入**:无订阅戒指 + 床垫数据 → Twin(`physiological`/`recovery`/睡眠分区,复用 RecoveryCoach/SafetyGuardian)
- 🆕 **CGM 短探针**:代谢深挖期 4-14 天,喂 `cgm/` 服务 → MetabolicSpecialist TIR
- 🆕 **直播私域获客闭环**:内容 → 问诊 → 履约 → 建档,测真实 CAC(估值杠杆②)
- 🎯 目标:CAC 显著低于行业 + Agent 主动闭环跑通 + 硬件依从率数据

### Phase 3(9-18 月):规模化 + 会员体系 + B 端探路
- 会员订阅体系(代谢管理终身会员)
- 检测+补剂复购供应链规模化
- 企业高管健康 / 体检机构合作探路
- 🎯 目标:可展示的 LTV/复购曲线,冲下一轮估值

## 5. 与技术 RFC 的映射(产品需求 → 技术方向)

| 产品需求 | 依赖的技术 RFC 方向 | 现状 |
|---|---|---|
| Agent 主动出手(异常推送) | 方向三(事件驱动主动 Agent) | Celery 雏形已有 |
| 12周 N-of-1 指标验证 | 方向五(闭环提为中枢) | episodes/personal_outcome 已有 |
| 代谢专家自主调用 | 方向一(specialist 工具化) | **PR #46 已落地 Phase A** |
| 长期因果记忆("上次你血糖高是…") | 方向二(因果记忆) | LongitudinalAnalyst 已有 |
| 戒指/床垫/CGM 无感采集 | 方向四(多模态/被动感知) | cgm 服务已有,硬件待接 |
| 难言之隐隐私 | 隐私 Tier 分级 | 已有基础 |

**结论**:产品 MVP 所需的技术零件**绝大部分已存在**,主要是「聚焦 + 串联 + 主动化」,不是从零造。这正是融资故事「已就绪、可演示」的底气。

## 6. 北极星指标与漏斗

**北极星**:**完成 ≥1 个 12 周 N-of-1 闭环且指标改善的用户数**(同时是产品价值、留存、估值故事的交汇点)。

**漏斗指标(每层单独埋点)**:
- 入口:直播/内容 → 问诊转化率、首单 CAC(估值杠杆②)
- 建档:首单 → 代谢 Twin 建档率(免费体检解读钩子的效果)
- 闭环:建档 → 启动 N-of-1 实验率 → 12周完成率
- 价值:**Outcome Delta**(肝酶/血脂/TIR 真实改善,估值杠杆①)
- 留存/变现:12周后续费率、检测+补剂复购、会员 LTV

**Agent 工程指标**(来自 RFC 方向九/十):主动推送命中率(防骚扰)、闭环验证准确率、单次对话成本。

## 7. 风险与边界(产品层)

| 风险 | 缓解 |
|---|---|
| 医疗合规(ED/处方药) | 不诊断不开方;问诊走持牌合作;补剂守《广告法》不作疾病治疗宣称 |
| 难言之隐隐私泄漏 | 端到端 + 隐名配送 + 隐私 Tier 最高级;数据加密分库 |
| Agent 主动出手扰民 | 默认沉默 + 打扰预算 + 用户可调频次(RFC 方向三) |
| 纯订阅转化死局(1.7%) | 服务即销售,直播私域获客(产品原则 5) |
| 硬件专利战 | 不自建,贴牌/集成(战略 §5) |
| 闭环 outcome 造不出来 | MVP 阶段就盯死 3 个真实改善案例,这是整个故事的地基 |

## 8. 第一步(把规划变行动)

**MVP 最小可跑闭环 = 一个垂直 demo**:
1. 选 1 个种子用户(脂肪肝/血脂异常的中年男性)
2. 上传体检 → AI 解读建 Twin → MetabolicSpecialist 出分析
3. 启动一个 12 周 Episode(饮食/补剂/运动干预)
4. 戒指/CGM 数据流入 → Agent 主动盯 → 中途调整
5. 12 周后产出指标对比卡

这一条 demo 跑通 = 验证了产品内核 + 产出第一个 outcome 数据点 + 路演有实物可演示。技术上 80% 零件已在(见 §5),主要工作是串联 + 主动化。
