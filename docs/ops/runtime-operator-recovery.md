# Runtime 服务器运维恢复

此入口只恢复后续准入，保留旧 Run、尝试、工具操作和回执的未决状态，不重放健康写入。现有管理员 HTTP 恢复接口及其身份校验保持原有要求；新增入口仅供通过已认证服务器访问的 Linux root 使用，不提供 HTTP 路由。

在已部署并验证的候选中，从后端工作目录使用该服务的 Python 环境执行 `scripts/runtime_operator_recovery.py review`，保存其无健康正文审核对象。经用户授权恢复未来准入后，将同一个对象通过 stdin 传给 `scripts/runtime_operator_recovery.py resume`。不得手工修改对象、冒充应用管理员或把未决记录改成未执行。

恢复事务锁定控制行，核对版本、代际、完整事件计数及未决 Run 摘要；审核结果过期、控制缺失、其他暂停原因或数据库不可用均拒绝恢复。审计对象和状态转换同一事务提交；后续新异常仍递增代际并重新触发暂停。失败输出不包含数据库连接信息或健康正文。

迁移回退采用应用回退、保留审计扩展：旧代码仍能读写原 system/admin 事件。不得删除 operator 事件、审核对象或撤销已保存的未知状态；如需结构降级，须另行审核迁移及完整审计保留方案。SQLite 迁移由 managed runner 的 checksum 保证一次执行，禁止直接重复重建 SQL。
