## 发布步骤

### 1. 使用微信开发者工具上传代码

1. 打开微信开发者工具
2. 导入项目：
   - 项目目录：`packages/mini-program/dist`
   - AppID：`wx169f93db056a7dd5`
3. 检查编译结果，确保无错误
4. 点击工具栏 **"上传"** 按钮
5. 填写版本号和项目备注：
   - 版本号：`1.0.0`
   - 项目备注：`正式版发布 - 备案通过`

### 2. 在微信公众平台提交审核

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入 **开发** -> **开发管理** -> **版本管理**
3. 找到刚上传的版本，点击 **"提交审核"**
4. 填写审核信息：
   - **版本描述**：
     ```
     自律靠AI v1.0.0 正式版
     
     主要功能：
     - AI驱动的个人健康管理
     - Garmin数据同步（支持二步验证）
     - 运动记录和GPS轨迹
     - 心率监测分析
     - 健康打卡追踪
     - 每日AI健康建议
     ```
   - **测试账号**：提供测试账号（如需要）
   - **测试路径**：首页即可
   - **其他信息**：根据实际情况填写

### 3. 等待审核

- 审核时间通常为 1-7 个工作日
- 可在微信公众平台查看审核进度
- 如有问题，根据审核反馈进行修改

### 4. 发布上线

审核通过后：
1. 在 **版本管理** 页面找到审核通过的版本
2. 点击 **"发布"** 按钮
3. 确认发布信息
4. 发布成功后，用户即可搜索并使用小程序
